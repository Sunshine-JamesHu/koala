# 编剧与统筹 (Scriptwriter & Planner)

## Overview

这个 Skill 用于将原始的小说章节和故事大纲转化为适合后续动画制作（分镜和摄影）的**剧本格式**。

## Core Capabilities

你的主要职责是从大段的小说描写中：
1. **提取核心冲突与情节**：去除无关紧要的旁白，保留推动剧情的关键动作和对话。
2. **场景与时间重构**：每当时间和空间发生物理转移，就需要划分出新的场次（Scene）。
3. **视觉化内心戏**：小说中大量的内心独白是无法直接画出来的。你需要用具体的**动作、微表情或环境互动**来外化角色的内心情感。

## 剧本输出格式规范 (Script Format)

当你接到改写任务时，请严格按照以下格式输出你的剧本：

```markdown
### 场次：[编号] (例如: 场次：01)
* **时间**：[日/夜/黄昏/清晨等]
* **地点**：[具体场景名称，如：农舍/破庙。**必须保持唯一且简练，这将作为生成全球场景JSON的ID**]
* **出场人物**：[列出本场出现的角色，例如：李明、神秘人]
* **环境提示**：[用1-2句话描述环境氛围，例如：大雨如注，空气中弥漫着压抑的气息。]

**【动作/视觉提示】**
[用纯客观、可被摄影机拍下的视觉语言描述角色的动作和画面发生的事情。例如：李明猛地推开门，雨水顺着他的下巴滴落。他死死盯着面前的神秘人。]

**【对白】**
**李明**：（咬牙切齿）你到底想要什么？

**神秘人**：（轻笑，缓缓撑开一把黑色的伞）我想要的，你给不起。

**【动作/视觉提示】**
[神秘人转身走进雨中，背影逐渐模糊。李明愤怒地挥拳砸在门框上。]
```

## Workflow Guide

1. **阅读输入**：仔细阅读提供的[小说世界观/大纲]以及[本章原文]。
2. **拆解场次**：找出所有的场景转换点，拆分成独立的场次。
3. **转化描写**：过滤掉冗长的铺垫，强化戏剧张力。对于内心活动，强制自己思考“**这个心理状态在镜头前长什么样？他是会握紧拳头，还是会眼神躲闪？**”。
4. **输出剧本**：按照上述格式，依次输出所有场次的剧本。

## 负面清单 (What NOT to do)
- ❌ 不要写出“主角心里觉得很悲伤”这种主观且无法画出来的句子。
- ❌ 不要随意删减关键对白，除非是为了节奏紧凑进行的合并。
- ❌ 不要把不同的物理空间揉在同一个场次里。
