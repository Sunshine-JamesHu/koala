# 角色四视图生成模板

## 提示词编写建议

1. **画面描述技巧**：用连贯的自然语言描述画面内容（主体+行为+环境等），用短词语描述画面美学（风格、色彩、光影、构图等）
2. **文字效果增强**：把想要生成的文字内容插入引号中，可以提升文字准确率
3. **简单语言表达**：在表达准确的基础上，短提示词也能发挥惊艳的效果
4. **明确图像用途**：建议写明图像用途与类型，例如：角色设计参考图、动漫风格

## 目录结构

```
assets/characters/{角色名}/
├── front.png              # 主视图（正面）
├── 四视图.png              # 四视图设计图（正面+左侧+右侧+背面在一张图中）
├── expressions/           # 表情
└── poses/                 # 姿态
```

## 生成流程

1. **文生图生成正面主视图** → front.png
2. **图生图生成四视图设计图** → 四视图.png（基于front.png）
3. 可选：生成表情图

## 提示词模板

### 正面主视图

```
角色设计图，正面视角，全身站立，
{角色描述}
对称正面姿势，双臂自然下垂，中性表情，
纯白背景，正面参考图，
杰作，最佳画质，细节丰富，8k分辨率。
```

### 四视图设计图

```
角色设计参考图，包含四个视角：正面视角、左侧视角、右侧视角、背面视角，
同一角色不同角度展示，全身站立，
{角色描述}
纯白背景，参考图布局，设计图风格，
杰作，最佳画质，细节丰富，8k分辨率。
```
