```

【角色设定】
【@图片1】辛月影，约20岁年轻女子，容貌甜美可爱，杏眼小脸，身材娇小玲珑。身穿破旧的青灰色粗布衣裳，打着深褐色补丁，衣角沾染了尘土。双螺髻有些散乱，几缕碎发垂落在脸侧。她此刻趴伏在冰冷泥土地面的中央位置，身体呈侧卧姿态，头部枕在交叠的双臂上，一动不动。

【运镜设计】
镜头类型: 远景 → 中景 → 近景
镜头角度: 俯视 → 平视
运镜方式: 缓慢推近 + 角度变化

0-3秒【环境铺陈期】:
- 景别: 远景，俯视
- 运镜: 镜头从屋梁高度缓慢匀速下移，掠过断裂的桌腿、散落的碎瓷
- 焦点: 从环境逐渐转移到地上的辛月影身上
- 画面: 月光光束如聚光灯般指向地面中央的青灰身影，青灯在角落投下跳动的阴影

3-6秒【苏醒征兆期】:
- 景别: 中景，角度逐渐转为平视
- 运镜: 镜头继续缓慢推进
- 焦点: 锁定在辛月影身上
- 动作: 【@图片1】辛月影的手指微微颤动，随后睫毛轻颤，眼皮缓缓掀开一条缝隙，眼神茫然

- 运镜: 镜头固定，轻微推进至面部
- 焦点: 辛月影的脸部表情
- 动作: 她用手肘撑起上半身，身体微微摇晃，茫然地望向角落阴影中轮椅的剪影

【情绪与表情变化】
0-3秒: 闭眼沉睡状态，表情平静
3-6秒: 睫毛颤动 → 眼神茫然困惑
6-10秒: 困惑 → 好奇注视，嘴角微微上扬

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与 深阴影 (#1A1A2E)
点缀色: 暖黄烛光 (#D4A574) 和 冷白月光 (#F0F0F0)
特殊效果: 空气中漂浮的尘埃在光线中闪烁
布光方式: 冷暖对比，烛光为暖色主光源，月光为冷色辅光源
对比度: 高对比，营造压抑氛围

【音效设计】

环境音:
- 深夜穿堂风呼啸而过
- 烛火噼啪作响
- 远处若有若无的虫鸣声
- 角色呼吸声由弱渐强

特殊音效:
- 3秒左右: 沈清起画外音（清朗却寒冽，略带嘲弄）

台词 (3秒左右出现):
【【@图片2】，沈清起，清冷低沉、冷漠地说道】："你自尽吧。"
（画外音，角落阴影中传来，略带混响，在辛月影刚刚撑起上身时响起）

背景音乐:
- 类型: 压抑悬疑配乐
- 特点: 低沉缓慢，营造不安氛围
- 乐器: 低音弦乐单音持续，偶尔加入不协和音
- 节奏: 几乎静止，每一个音符都被拉长
- 音量: 20%，极低，突出环境音和台词
- 情绪: 压抑、不安、悬念

【画面质感】
- 景深: 从深景深（环境清晰）逐渐过渡到浅景深（聚焦角色）
- 运动效果: 镜头下移平稳流畅，无运动模糊
- 细节度: 高细节，碎瓷片纹理、灰尘粒子清晰可见
- 特殊效果: 月光体积光，烛光摇曳光晕，尘埃粒子飘浮
- 色彩处理: 整体偏冷色调，烛光区域带暖色
- 动态范围: 高动态范围，暗部细节保留

【情绪氛围】
整体画面昏暗压抑，透着凄凉与萧索。辛月影娇小的身躯在破败环境中显得无助。烛光与月光的冷暖对比象征着她内心的迷茫与外界危机的冲突。沈清起突兀的"你自尽吧"打破平静，为整个故事奠定悬念基调。画面充满悬念——她会如何面对这个陌生的世界？

精致细节, 流畅动作, 柔和电影级光影, 景深模糊, 8k画质, Unreal Engine 5质感, 电影级3D动画

--aspect_ratio 16:9
```
