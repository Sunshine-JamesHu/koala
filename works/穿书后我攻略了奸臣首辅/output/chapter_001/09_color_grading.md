#### 渐变调色 (场景内变化)

**表演阶段**:
```
色温: 相对暖 (辛月影努力表演)
饱和度: 稍高 (夸张表演)
效果: 有一丝"生气"
```

**玩味反应**:
```
色温: 开始转冷

```

**阴鸷结尾**:
```
色温: 最冷

```

#### 调色预设描述
```
gradual darkening cold tone,
vignette effect increasing,
theatrical to ominous transition,
suspenseful cliffhanger atmosphere,
fading to darkness ending
```
