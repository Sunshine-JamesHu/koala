## 整体音乐风格

### 章节基调
- **主要风格**: 古风悬疑 / 影视配乐
- **乐器配置**: 古琴、箫、弦乐、低音提琴、环境合成器
- **节奏特点**: 慢→中→慢，配合情绪起伏
- **情绪基调**: 诡异悬疑→恐惧紧张→悬念收尾

### 主题音乐

#### 辛月影主题 (求生)
```
风格: 灵动、坚韧
乐器: 古琴、琵琶
特点: 音域偏高、节奏不稳定、带有希望感
```

#### 沈清起主题 (危险)
```
风格: 冷冽、优雅、危险
乐器: 箫、低音弦乐
特点: 音域偏低、节奏缓慢、带有压迫感
```

## 场景配乐详细设计

### 场景 1-2: 苏醒与病娇亮相

**基本信息**:
- 场景情绪: 悬疑、诡异、惊艳
- 音乐类型: 氛围铺陈
- 建议时长: 26秒
- 强度曲线: 渐强 → 平稳

**音乐描述**:
```
风格: 悬疑古风氛围音乐
乐器: 箫(主) + 古琴(点缀) + 低音提琴(持续) + 环境合成器
节奏: 60 BPM, 缓慢不规则
旋律: 箫吹奏断续的低音旋律，无明确调性
和声: 小调，不协和音程营造不安
```

**情绪关键词**:
```
eerie, suspenseful, ancient Chinese atmosphere,
dark ambient, mystery, foreboding,
traditional Chinese instruments,
slow tempo, minor key,
background music, instrumental, no vocals
```

**参考风格**:
- 《琅琊榜》悬疑场景配乐
- 《甄嬛传》阴谋氛围音乐

**音乐结构**:
| 时间 | 内容 | 情绪 |
|------|------|------|
| 0-8秒 | 低音铺陈，环境音开始 | 压抑开场 |
| 8-14秒 | 箫声断续进入 | 神秘感 |
| 14-20秒 | 月光亮相，箫声略扬 | 惊艳感 |
| 20-26秒 | 瞳孔收缩，音效配合 | 惊悚转折 |

和声: 减和弦、不协和音程

tense, suspenseful, thriller atmosphere,

building tension, climax approaching,
ancient Chinese drama score,
background music, instrumental, no vocals
```

**参考风格**:
- 《琅琊榜》紧张对峙配乐

**音乐结构**:
| 时间 | 内容 | 情绪 |
|------|------|------|
| 0-5秒 | 弦乐颤音开始 | 紧张感建立 |
| 5-11秒 | 心跳节奏加入，速度加快 | 恐惧加剧 |
| 11-16秒 | 剑鸣音效配合，音乐压低 | 杀意凛然 |

乐器: 打击乐(急促) + 弦乐(快速) → 低音(压抑)
节奏: 100 BPM → 60 BPM，急促转缓慢
旋律: 无明确旋律，节奏为主
和声: 不协和 → 小调和弦
```

**情绪关键词**:

action burst, sudden movement,
rapid percussion, urgent strings,
desperate escape attempt,
then sudden stop, hopeless realization,
cold despair, trapped feeling,
ancient Chinese drama score,
background music, instrumental, no vocals
```

**参考风格**:
- 动作电影追逐配乐转悲伤配乐

**音乐结构**:

旋律: 无明确旋律，和声进行为主
和声: 减和弦进行，最后悬而未决
```

```
suspense, uncertain outcome,
tense strings, low flute,
building tension gradually,
unresolved ending, cliffhanger,
ominous atmosphere, foreboding,
ancient Chinese drama score,
background music, instrumental, no vocals
```

- 悬疑剧悬念结尾配乐

**音乐结构**:
