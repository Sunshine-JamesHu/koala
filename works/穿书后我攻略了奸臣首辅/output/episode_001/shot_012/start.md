# Shot 012 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 悬而未决

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 青灯摇曳, 冷青色与暗金色光线交织. 斑驳土墙, 腐朽木梁. 氛围紧张对峙.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发凌乱, 身穿褪色的淡青色交领襦裙. 站立, 直视沈清起. 眼神坚定中带着紧张.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光审视与怀疑. 黑色长发束起, 身穿玄色锦袍. 坐在轮椅上, 剑势依旧, 冷笑未消.

【构图与运镜】
镜头类型: 中景 (medium shot)
镜头角度: 平视 (eye level)
焦点: 两人对峙
景深: 浅, 背景高度虚化

【画面描述】
中景构图. 辛月影站在右侧, 直视沈清起, 眼神坚定中带着紧张. 沈清起坐在左侧轮椅上, 目光审视与怀疑, 剑势依旧, 冷笑未消. 两人形成对角线构图, 空气中弥漫着紧张的火药味. 青灯摇曳, 光影交错.

【色调与光影】
主色调: 冷青色与暗金色交织 (#3A4A5C, #8B7355)
点缀色: 暖黄烛光 (#D4A574), 深阴影 (#1A1A2E)
布光方式: 冷暖交织
对比度: 高

【画面质感】
- 景深: 浅, 两人清晰
- 细节: 坚定眼神, 审视目光
- 质感: 紧张对峙, 电影质感
```
---

## 关键视觉参考
```
【构图要点】
- 双人对角线构图
- 辛月影站立(右)
- 沈清起坐轮椅(左)
【情绪暗示】
- 紧张对峙
- 博弈未分胜负
```
