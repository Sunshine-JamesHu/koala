# Shot 012 - 尾帧图片生成提示词
> 尾帧可作为下一分镜的首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 悬而未决

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 青灯在角落摇曳, 投射出长长的影子. 冷青色与暗金色光线交织. 斑驳土墙, 腐朽木梁, 破损窗棂清晰可见. 氛围紧张对峙, 命运未卜, 留白构图.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发凌乱, 身穿褪色的淡青色交领襦裙. 站立在画面右侧, 身形在阴影中显得渺小. 眼神坚定, 等待回应.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光审视. 黑色长发束起, 身穿玄色锦袍. 坐在轮椅上位于画面左侧, 身形同样被阴影包围. 剑势依旧, 目光如刀.

【构图与运镜】
镜头类型: 全景 (full shot)
镜头角度: 平视 (eye level)
焦点: 两人对峙的全景, 留白构图
景深: 中, 环境清晰可见

【画面描述】
全景构图定格, 留白效果. 辛月影和沈清起形成对角线构图, 两人在破旧房屋中显得渺小, 被阴影包围. 青灯在角落摇曳, 投射出长长的影子, 光影交错. 冷青色与暗金色交织. 危机悬而未决, 命运未卜. 为下一集埋下悬念. 淡出效果.

【色调与光影】
主色调: 冷青色与暗金色交织 (#3A4A5C, #8B7355)
点缀色: 暖黄烛光 (#D4A574), 深阴影 (#1A1A2E)
布光方式: 冷暖交织, 阴影深重, 留白暗调
对比度: 高, 整体偏暗

【画面质感】
- 景深: 中, 环境清晰
- 细节: 对角线构图, 青灯影子
- 质感: 留白悬念, 电影质感
```
