# Shot 008 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 智谋觉醒

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 仅有一盏青铜油灯摇曳. 斑驳土墙, 腐朽木梁. 氛围绝望.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发凌乱散落, 身穿褪色的淡青色交领襦裙. 跪坐在地, 头微微低垂, 双肩颤抖. 眼神绝望无助.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光阴鸷. 黑色长发束起, 身穿玄色锦袍. 轮椅在画面边缘, 长剑指向辛月影.

【构图与运镜】
镜头类型: 特写 (close up)
镜头角度: 平视 (eye level)
焦点: 辛月影低垂的面部
景深: 浅, 背景高度虚化

【画面描述】
特写构图. 辛月影跪坐在地, 头微微低垂, 双肩颤抖. 眼神绝望无助, 长发凌乱散落. 烛光微弱, 在她脸上投射出明暗交替的光影. 沈清起的剑尖在画面边缘可见. 绝望的深渊.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 烛光主导, 冷暖交织
对比度: 中到高

【画面质感】
- 景深: 浅, 面部清晰
- 细节: 低垂的面部, 颤抖的双肩
- 质感: 绝望无助, 电影质感
```
