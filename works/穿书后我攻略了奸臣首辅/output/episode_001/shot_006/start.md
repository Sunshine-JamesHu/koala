# Shot 006 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 愤怒指责

【场景环境】
古代边陲小镇门外门廊, 夜晚. 门廊两侧有火把燃烧, 暖黄与冷蓝的光线形成对比. 古旧的木门框在画面中清晰可见. 氛围紧张.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发凌乱, 身穿褪色的淡青色交领襦裙. 刚冲到门口, 身体前倾, 还没来得及看清前方有人.
霍齐, 30岁左右的男子, 护卫. 魁梧的身材, 方正的面庞, 浓眉虎目. 身穿灰色劲装, 腰间佩刀. 堵在门口, 身形如山, 面露怒容.

【构图与运镜】
镜头类型: 中景 (medium shot)
镜头角度: 平视 (eye level)
焦点: 门框构图, 两人即将碰撞
景深: 浅, 背景高度虚化

【画面描述】
中景构图, 门框形成天然牢笼. 辛月影刚冲到门口, 身体前倾, 还没看清前方有人. 霍齐如山一般堵在门口, 身形魁梧, 面露怒容. 火把的光芒在门廊跳动, 暖黄与冷蓝形成对比. 碰撞即将发生.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 火把暖黄 (#D4A574), 冷蓝阴影 (#2A3A4C)
布光方式: 冷暖对比
对比度: 高

【画面质感】
- 景深: 浅, 背景虚化
- 细节: 门框构图, 火把光芒
- 质感: 紧张悬疑, 电影质感
```
