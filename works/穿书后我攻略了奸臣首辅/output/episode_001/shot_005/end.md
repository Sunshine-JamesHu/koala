# Shot 005 - 尾帧图片生成提示词

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 紧张追逐

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 破损的门框, 门缝透入微弱冷光. 斑驳土墙, 腐朽木梁. 氛围剑拔弩张.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤泛红. 黑色长发凌乱不堪, 身穿褪色的淡青色交领襦裙, 裙摆散乱. 靠在门框上, 喘息不止, 胸口起伏剧烈. 眼中绝望和恐惧交织, 瞳孔收缩.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光阴鸷嘲讽. 黑色长发束起, 身穿玄色锦袍. 长剑稳稳举起, 剑尖指向辛月影. 嘴角带着冷笑, 眼中审视这只困兽.

【构图与运镜】
镜头类型: 中景 (medium shot)
镜头角度: 平视 (eye level)
焦点: 辛月影靠在门框的身影
景深: 浅, 背景完全虚化

【画面描述】
中景构图定格. 辛月影靠在破损的门框上, 喘息不止, 面色苍白泛红, 长发凌乱, 襦裙散乱. 眼中绝望和恐惧交织, 无路可逃. 沈清起长剑稳稳指向她, 嘴角冷笑, 眼中带着审视和嘲讽. 烛光与剑光交织. 逃无可逃的困境.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 剑光银白色 (#E8E8E8), 暖黄烛光 (#D4A574)
布光方式: 冷暖对比, 剑光闪烁
对比度: 高

【画面质感】
- 景深: 浅, 只有两人清晰
- 细节: 喘息的表情, 凌乱的长发
- 质感: 无路可逃, 电影质感
```
