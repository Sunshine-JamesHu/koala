## 场景 1：谎言自证

分布

### 基本信息
- **场景情绪**: 紧张、绝望、赌命
- **音乐类型**: 紧张弦乐 + 孤寂氛围
- **建议时长**: 约23秒（镜头1-4)
- **强度曲线**: 渐强 → 平稳 → 渐弱

```
时间轴: 情绪 | 音乐 | 强度
|--------|------|----------|----------|
| 0s-5s | 绝望赌命 | 弦乐紧张开场，压抑 | 中低 |
| 5s-12s | 审视等待 | 弦乐持续，略减 | 中 |
| 12s-16s | 霍齐行动 | 弦乐渐弱，留白 | 低 |
| 16s-23s | 转场安静 | 孤寂氛围音 | 极低 |
```
### 音乐描述

**情绪曲线**: 紧张 → 审视 → 行动 → 留白

**节奏**: 70-80 BPM → 60 BPM → 80 BPM → 50 BPM
**调性**: 小调 → 小调转大调 → 大调 → 小调

**乐器**: 弦乐组（小提琴、大提琴、低音提琴）
**风格**: 紧张压抑、孤寂、深夜

**参考曲目**:
- 《魔道祖师》紧张场景配乐
- 《琅琊榜》悬念音乐
- 古风悲剧弦乐

**乐器**: 弦乐组 + 遶留钢琴温暖旋律 + 大提琴悲伤主题

## 场景过渡音乐设计

分布

### 过渡1: 场景1 → 场景2
- **类型**: 延续 + 变奏
- **方式**: 弦乐主题保持，但加入悲伤元素
- **时长**: 2秒
- **情绪**: 压抑 → 悲伤

```
音乐保持压抑弦乐，但逐渐加入大提琴悲伤旋律，预示即将到来的悲剧性场景
```
分布

### 过渡2: 场景2 → 场景3
- **类型**: 叟奏
- **方式**: 悲伤弦乐逐渐转为温暖钢琴
- **时长**: 3秒
- **情绪**: 悲凉 → 温暖
```
音乐从悲凉弦乐逐渐加入钢琴温暖和弦，大提琴悲伤旋律减弱，钢琴温暖旋律增强，为忠诚主题做铺垫
```
分布

### 过渡3: 场景3 → 场景4
- **类型**: 切断（硬切）
- **方式**: 温暖音乐突然切断，转为悬疑低频
- **时长**: 1秒
- **情绪**: 宽慰 → 惊恐
```
温暖音乐突然结束，立即转为紧张的悬疑低频，配合场景从室内到室外的转换
```
