## 字幕与配音配合

### 配合要点
1. **时间同步**: 字幕出现与配音开始严格同步
2. **阅读时间**: 单行字幕显示时间 ≥ 1.5秒
3. **换行规则**: 单行超过15字自动换行
4. **标点处理**: 保留原标点，但不单独占行首尾

### 示例
```
配音: "死我一人对你而言虽不足惜，但害你之人便就逍遥法外了！"
字幕:
死我一人对你而言虽不足惜，
但害你之人便就逍遥法外了！
```
