# Shot 006 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 假装关心

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀. 沈清起坐在画面左侧的轮椅上.

【角色设定】
辛月影, 18岁中国古代女子, 正快步走向沈清起. 精致娇美的五官, 白皙透亮的皮肤, 杏眼中带着惊恐和心疼的神色, 眼眶开始泛红. 乌黑如墨的长发及腰, 梳半扎半散的少女发式. 身穿月白色对襟短襦配淡粉色百褶裙. 她刚刚发现沈清起手上的鲜血, 正带着惊恐和心疼的表情快步上前.

沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上. 苍白如纸的病态白皙皮肤, 狭长凤眼, 目光阴鸷. 身穿玄色交领长袍. 他的右手紧握碎瓷片, 鲜血从指缝滴落. 看到辛月影上前, 目光更加阴鸷.

【构图与运镜】
镜头类型: 中近景 (medium close-up)
镜头角度: 平视 (eye level)
焦点: 辛月影走向沈清起
景深: 中等

【画面描述】
中近景镜头, 辛月影正带着惊恐和心疼的表情快步走向沈清起. 她的眼眶开始泛红, 杏眼中流露出焦急和担忧. 淡粉色衣裙在行走中微微飘动. 沈清起坐在画面左侧的轮椅上, 阴鸷的目光注视着走近的辛月影, 右手仍然紧握碎瓷, 鲜血滴落. 烛光在两人之间摇曳, 营造出紧张而复杂的氛围.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 血红 (#8B0000), 淡粉衣裙 (#FFD6E0)
布光方式: 烛光照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 辛月影焦急表情, 沈清起阴鸷目光
- 质感: 紧张复杂, 电影质感
```
