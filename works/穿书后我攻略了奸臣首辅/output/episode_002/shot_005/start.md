# Shot 005 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 惊恐发现

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀.

【角色设定】
辛月影, 18岁中国古代女子, 刚从地上站起或半蹲姿态. 精致娇美的五官, 白皙透亮的皮肤, 杏眼清亮. 乌黑如墨的长发及腰, 梳半扎半散的少女发式. 身穿月白色对襟短襦配淡粉色百褶裙. 她刚刚收拾完碎瓷, 听到滴答滴答的液体滴落声, 正循声望去. 眉头微皱, 眼神中带着疑惑和警觉, 想知道那是什么声音.

【构图与运镜】
镜头类型: 特写 (close-up)
镜头角度: 平视 (eye level)
焦点: 辛月影面部
景深: 浅, 背景虚化

【画面描述】
特写镜头, 聚焦在辛月影的面部. 她刚刚收拾完碎瓷, 正在起身或保持半蹲姿态. 突然听到滴答滴答的液体滴落声, 她循声望去, 眉头微皱, 眼神中带着疑惑和警觉. 杏眼中倒映着摇曳的烛光, 嘴唇微微抿起. 整体表情呈现疑惑和警觉的状态, 仿佛在问"那是什么声音?". 背景是昏暗的房间, 沈清起的身影在画面边缘隐约可见.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 淡粉衣裙 (#FFD6E0)
布光方式: 烛光侧面照明
对比度: 高

【画面质感】
- 景深: 浅, 面部清晰
- 细节: 疑惑眼神, 眉头微皱
- 质感: 警觉疑惑, 电影质感
```
