# Shot 004 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 内心独白

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁, 破损的窗棂. 冷青灰色调为主, 暖黄烛光点缀. 地面上散落着碎瓷片, 在烛光下反射着微弱的光.

【角色设定】
辛月影, 18岁中国古代女子, 蹲在地上. 精致娇美的五官, 白皙透亮的皮肤, 杏眼清亮灵动. 乌黑如墨的长发及腰, 梳半扎半散的少女发式, 头发从肩上垂落, 遮住部分面容. 身穿月白色对襟短襦配淡粉色百褶裙, 裙摆在蹲姿下铺散在地面. 她正蹲下身, 伸手准备捡拾地上的碎瓷片, 外表楚楚可怜, 顺从地准备做清洁工作.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 俯拍 (high angle)
焦点: 辛月影蹲下的身影
景深: 中等, 地面碎瓷片也较清晰

【画面描述】
俯拍中景镜头, 辛月影蹲在地上, 正准备收拾散落的碎瓷片. 她的姿态楚楚可怜, 低头看着地面, 头发从肩上垂落. 淡粉色百褶裙在蹲姿下铺散在地面上, 与冰冷的地板形成对比. 她的手正伸向地上的碎瓷片, 动作小心翼翼. 地面上散落着大小不一的碎瓷片, 在烛光下反射着微弱的光. 整体画面营造出楚楚可怜、顺从工作的氛围.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 淡粉衣裙 (#FFD6E0)
布光方式: 烛光从上方斜照, 俯拍角度
对比度: 中等

【画面质感】
- 景深: 中等
- 细节: 蹲姿, 碎瓷片, 衣裙铺散
- 质感: 楚楚可怜感, 电影质感
```
