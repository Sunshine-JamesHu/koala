# Shot 007 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 悲凉质问

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀. 背景虚化处理, 突出沈清起的面部.

【角色设定】
沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上. 苍白如纸的病态白皙皮肤, 轮廓分明的棱角坚毅面容. 狭长凤眼, 眼眶微陷, 目光阴鸷中带着复杂的情绪. 剑眉斜飞入鬓, 眉宇间带着阴郁. 嘴唇淡薄苍白. 黑色长发略显凌乱披散. 身穿玄色交领长袍. 他刚刚被辛月影的话语触动, 正低头沉默, 凤眼微阖, 似乎在消化这一切. 表情复杂, 阴鸷中带着一丝动摇和困惑.

【构图与运镜】
镜头类型: 特写 (close-up)
镜头角度: 低角度仰拍 (low angle)
焦点: 沈清起面部
景深: 浅, 背景虚化

【画面描述】
特写镜头, 聚焦在沈清起的面部. 他刚刚被辛月影那句"相公, 你若是心头实在难过, 便就骂我两声, 切莫伤损自己的身体"触动, 正低头沉默, 凤眼微阖. 苍白病态的面容在烛光下显得更加阴郁, 眉宇间带着复杂的情绪. 他的内心在挣扎, 一方面怀疑辛月影的真实意图, 一方面又被她的话语触动. 低角度仰拍增强了悲凉和压迫感, 眼窝处投下深沉的阴影.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 烛光从下方斜照, 低角度
对比度: 高

【画面质感】
- 景深: 浅, 面部清晰
- 细节: 凤眼微阖, 复杂表情, 眼窝阴影
- 质感: 沉默挣扎, 电影质感
```
