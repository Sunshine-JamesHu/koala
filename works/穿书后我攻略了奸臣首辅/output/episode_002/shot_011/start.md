# Shot 011 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 惊慌逃命

【场景环境】
古代边陲小镇房屋外门廊, 夜晚. 狭窄的破旧门廊, 不平的石板地面, 茅草屋檐部分脱落. 月光微弱, 偶有云层遮蔽. 冷蓝色调为主, 屋内烛光透过门缝形成细弱光线. 寒风萧瑟.

【角色设定】
辛月影, 18岁中国古代女子, 刚从门内出来. 精致娇美的五官, 白皙透亮的皮肤, 杏眼中带着无奈. 乌黑如墨的长发及腰, 被夜风吹动. 身穿月白色对襟短襦配淡粉色百褶裙, 没有淡青色外衣. 她刚刚被沈清起赶出来, 表情顺从无奈, 正走在门廊上. 夜风吹动她的衣裙和发丝.

【构图与运镜】
镜头类型: 全景 (full shot)
镜头角度: 平视 (eye level)
焦点: 辛月影
景深: 中等, 背景适度虚化

【画面描述】
全景镜头, 辛月影刚刚从门内出来, 走在破旧门廊上. 她的表情顺从无奈, 刚刚被沈清起说"滚"赶出来. 月光微弱, 她的身影在夜色中显得单薄无助. 夜风吹动她的淡粉色衣裙和黑色长发, 茅草屋檐在风中微微颤动. 门缝透出微弱的暖黄烛光, 与冷蓝的夜色形成对比. 远处是边陲小镇模糊的轮廓. 整体画面呈现无奈被逐的孤独感.

【色调与光影】
主色调: 冷蓝色 (#1E272E)
点缀色: 月光 (#BDC3C7), 门缝烛光 (#D4A574), 淡粉衣裙 (#FFD6E0)
布光方式: 月光主光源, 门缝烛光点缀
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 辛月影无奈表情, 夜风吹动衣裙
- 质感: 孤独无奈, 电影质感
```
