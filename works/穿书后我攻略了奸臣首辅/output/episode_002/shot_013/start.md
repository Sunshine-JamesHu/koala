# Shot 013 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 悬念结尾

【场景环境】
古代边陲小镇外的夜色小路, 夜晚. 崎岖的小路, 远处是破旧房屋的轮廓. 月光微弱, 云层遮蔽. 冷蓝色调为主. 寒风萧瑟.

【角色设定】
辛月影, 18岁中国古代女子, 站在小路上. 精致娇美的五官, 白皙透亮的皮肤, 杏眼警觉不安. 乌黑如墨的长发凌乱. 身穿月白色对襟短襦配淡粉色百褶裙. 她正回头看向破旧房屋的方向, 表情警觉不安, 眼神中带着担忧.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 平视 (eye level)
焦点: 辛月影回头的姿态
景深: 中等

【画面描述】
中景镜头, 辛月影站在夜色的小路上, 正回头看向破旧房屋的方向. 她的表情警觉不安, 杏眼中带着担忧和恐惧. 黑色长发在夜风中凌乱飘动, 淡粉色衣裙在冷蓝的夜色中显得格外单薄. 远处破旧房屋的轮廓在月光下隐约可见, 窗纸黑洞洞的. 整体画面呈现不安和悬疑的氛围, 是本集悬念结尾的开端.

【色调与光影】
主色调: 冷蓝色 (#1E272E)
点缀色: 月光 (#BDC3C7), 淡粉衣裙 (#FFD6E0)
布光方式: 月光微弱照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 回头姿态, 警觉表情, 凌乱发丝
- 质感: 悬疑不安, 电影质感
```
