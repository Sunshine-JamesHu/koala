# 配乐方案 - 第1章 你自尽吧

## 整体音乐风格

- **主要风格**: 古风悬疑/紧张氛围
- **乐器配置**: 古琴、箫、低音提琴、轻打击乐
- **节奏特点**: 慢到中速、节奏不稳
- **情绪基调**: 压抑、紧张、惊悚、悬疑
- **参考风格**: 《魔道祖师》危机场景配乐

## 场景 1: 苏醒与审判

### 基本信息

- **场景情绪**: 阴森、压抑、惊悚
- **音乐类型**: 悬疑氛围音乐
- **建议时长**: 17秒
- **强度曲线**: 低开 → 略升 → 悬停

### 音乐描述

```
风格: dark ancient atmosphere, suspenseful ambient
乐器: 低音古琴 + 远处箫声 + 轻微弦乐铺垫
节奏: 60 BPM, 极简, 不规则停顿
旋律: 无明显旋律, 以音色和和声营造氛围
和声: 小调, 不协和音程, 低音持续音
```

```

low guqin, distant xiao flute,

60 BPM, irregular pauses,
oppressive silence,
Chinese donghua suspense scene,
background music, instrumental, no vocals
```

## 主题音乐设计

### 女主（辛月影）主题动机

```
特点: 灵动、俏皮但带有紧张感
乐器: 古筝 + 琵琶
音程: 大二度到小三度，活泼跳跃
使用场景: 女主表演、机智应对时
```

### 沈清起主题动机

```
特点: 阴冷、深沉、压抑
乐器: 低音古琴 + 大提琴
音程: 小二度、减五度，不协和
使用场景: 沈清起审视、威胁时
```

### 危机主题

```
特点: 紧张、压迫
乐器: 弦乐群 + 定音鼓
节奏: 不规则、停顿多
使用场景: 剑锋威胁、逃跑场景
```
