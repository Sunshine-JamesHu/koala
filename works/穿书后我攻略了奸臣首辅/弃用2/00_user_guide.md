## 使用流程

### 阶段1: 生成角色/场景参考图

1. **打开 Nano Banana Pro**
2. **生成角色参考图**:
   - 打开 `02_character_refs.md`
   - 复制角色描述提示词
   - 生成辛月影、沈清起、霍齐的三视图/表情卡
   - 保存为 `[角色名]-三视图.png`

3. **生成场景参考图**:
   - 打开 `03_scene_refs.md`
   - 复制场景8视角卡提示词
   - 生成场景图
   - 保存为 `破败草屋-室内-8视角.png`

### 阶段2: 生成关键帧图片

1. **打开 `04_image_prompts.md`**
2. **按顺序生成关键帧**:
   - 每个镜头有详细的提示词
   - 上传对应的角色参考图保持一致性
   - 保存为 `[镜头编号]-[描述].png`

### 阶段3: 生成视频分镜参考图

1. **打开 `04c_video_storyboard_refs.md`**
2. **为每个视频生成分镜参考图**:
   - 6格分镜用于8秒视频 (Veo)
   - 8格分镜用于10秒视频 (可灵)
   - 保存为 `[视频编号]-分镜参考.png`

### 阶段4: 生成视频

#### 方案A: 使用 Veo3.1 Fast (8秒视频)

1. **打开 Veo3.1 Fast**
2. **选择视频编号** (V01-V05 for Chapter 2)
3. **复制提示词**:
   - 打开 `05_video_prompts_veo.md`
   - 复制对应视频的提示词
4. **上传参考图**:
   - 上传视频分镜参考图
   - 上传角色参考图
5. **生成视频** (8秒)
6. **保存为 `[视频编号].mp4`**

#### 方案B: 使用可灵动画 (5秒/10秒视频)

1. **打开可灵动画**
2. **选择视频编号** (K01-K05 for Chapter 2)
3. **复制提示词**:
   - 打开 `06_video_prompts_kling.md`
   - 复制对应视频的提示词
4. **上传参考图**:
   - 上传视频分镜参考图
   - 上传角色参考图
5. **选择时长** (5秒或10秒)
6. **生成视频**
7. **保存为 `[视频编号].mp4`**

### 阶段5: 后期制作

1. **调色**:
   - 参考 `07_color_grading.md`
   - 使用推荐的LUT和色彩参数

2. **音效**:
   - 参考 `08_sound_design.md`
   - 添加环境音和动作音效

3. **配乐**:
   - 参考 `09_music_guide.md`
   - 选择或创作符合情绪的背景音乐

4. **配音**:
   - 参考 `10_voice_direction.md`
   - 指导声优按角色设定配音

5. **合成**:
   - 整合视频、音频、字幕
   - 输出最终成片

## 重要提示

### 保持角色一致性

1. **始终上传相同的角色参考图**
2. **使用统一的风格前缀**:
   ```
   3D动画渲染, Unreal Engine 5质感, 国漫风格, Chinese Donghua Style, 古风唯美
   ```
3. **使用统一的负向提示词**:
   ```
   low quality, worst quality, blurry, distorted, deformed, ugly, bad anatomy,
   bad proportions, modern elements, western style, 2d flat, sketch, line art,
   text, watermark, signature, photo realistic, plastic look
   ```

### 跨镜头衔接

- 每个视频提示词包含"给上一镜头的衔接信息"
- 确保连续镜头的场景、角色位置一致
- 注意第1章结尾与第2章开头的衔接

## 常见问题

**Q: 为什么生成的图片与预期不符?**
A: 确保上传了正确的角色参考图，并使用完整的提示词。

**Q: 视频生成时间过长怎么办?**
A: Veo3.1 Fast 生成约需5-10分钟，可灵约需3-5分钟。建议先生成关键帧图片确认效果。

**Q: 如何保持跨章节的一致性?**
A: 使用同一个 style.json 配置，并始终使用相同的核心角色描述。

**Q: 负向提示词在哪里?**
A: 每个提示词下方都有对应的负向提示词，复制时请一并使用。
