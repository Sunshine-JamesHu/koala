# Shot 009 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 智谋博弈

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 仅有一盏青铜油灯摇曳. 冷暖光线交织. 斑驳土墙, 腐朽木梁.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发凌乱, 身穿褪色的淡青色交领襦裙. 跪坐在地, 眼神坚定冷静, 准备起身.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光阴鸷. 黑色长发束起, 身穿玄色锦袍. 坐在轮椅上, 剑势依旧, 审视辛月影.

【构图与运镜】
镜头类型: 中近景 (medium close shot)
镜头角度: 平视 (eye level)
焦点: 两人对峙
景深: 浅, 背景高度虚化

【画面描述】
中近景构图. 辛月影跪坐在地, 眼神坚定冷静, 准备起身反击. 沈清起坐在轮椅上, 剑势依旧, 审视着她. 烛光在两人之间摇曳, 形成明暗交替的光影. 博弈即将开始.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 暖黄烛光 (#D4A574), 暗金色 (#8B7355)
布光方式: 冷暖交织
对比度: 中到高

【画面质感】
- 景深: 浅, 两人清晰
- 细节: 坚定眼神, 审视目光
- 质感: 智谋博弈, 电影质感
```
