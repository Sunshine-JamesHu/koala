# Shot 004 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 生死威胁

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 仅有一盏青铜油灯摇曳. 冷青色剑光即将出现. 斑驳土墙, 腐朽木梁. 荷兰角构图.

【角色设定】
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 棱角分明的面容, 狭长凤眼目光阴鸷冷酷. 黑色长发束起, 身穿玄色锦袍. 手正要举起三尺青锋剑, 剑身微微抬起.
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发散乱, 身穿褪色的淡青色交领襦裙. 刚从震惊中回神, 眼神中带着不安和预感.

【构图与运镜】
镜头类型: 中景 (medium shot)
镜头角度: 荷兰角 (dutch angle), 约15度倾斜
焦点: 两人对峙
景深: 浅, 背景高度虚化

【画面描述】
荷兰角中景构图. 沈清起坐于轮椅上, 身体微微前倾, 手中长剑正在缓缓抬起, 剑锋即将指向辛月影. 辛月影站在对面, 眼神中带着不安的预感. 烛光在两人之间摇曳, 气氛压抑紧张. 危机即将爆发的前夕.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 冷暖对比
对比度: 高

【画面质感】
- 景深: 浅, 背景虚化
- 细节: 剑身微光, 两人表情
- 质感: 压抑紧张, 电影质感
```
