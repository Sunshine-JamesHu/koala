# Shot 005 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 紧张追逐

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 破损的门框在画面一侧可见. 斑驳土墙, 腐朽木梁. 氛围紧张.

【角色设定】
辛月影, 18岁左右的中国古代女子. 精致娇美的五官, 白皙透亮的皮肤. 黑色长发散乱, 身穿褪色的淡青色交领襦裙. 背靠墙壁, 眼神绝望. 刚刚做出逃跑决定的瞬间, 眼中闪过一丝决绝.
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 狭长凤眼目光阴鸷. 黑色长发束起, 身穿玄色锦袍. 坐在轮椅上, 长剑稳稳指向辛月影, 等待她的反应.

【构图与运镜】
镜头类型: 中景 (medium shot)
镜头角度: 平视 (eye level)
焦点: 两人对峙
景深: 浅, 背景高度虚化

【画面描述】
中景构图. 辛月影背靠墙壁, 眼神中绝望与决绝交织. 她正准备做出逃跑的决定, 身体微微前倾. 沈清起坐在轮椅上, 长剑稳稳指向她, 嘴角带着冷笑. 烛光摇曳, 氛围紧张. 逃跑即将发生的前夕.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C) 与深阴影 (#1A1A2E)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 冷暖对比
对比度: 高

【画面质感】
- 景深: 浅, 背景虚化
- 细节: 眼神变化, 身体姿态
- 质感: 紧张悬疑, 电影质感
```
