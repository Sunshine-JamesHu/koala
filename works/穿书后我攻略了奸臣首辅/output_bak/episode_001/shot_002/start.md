# Shot 002 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 催眠神秘

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 深邃黑暗的空间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁, 獐损的窗棾. 大面积的阴影笼罩房间, 冷青灰色调为主, 暖黄烛光点缀.

【角色设定】
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 毫无血色. 轮廓分明棱角坚毅, 狭长凤眼目光阴鸷深邃. 巨色淡薄苍白. 黑色长发略显凌乱地披散. 身穿破旧的玄色交领长袍, 袖口、衣摆可见磨损痕迹. 他坐在一把破败的木制轮椅上, 轮椅的坐垫破损, 铁轮生锈. 整体散发着落魄却危险的气息.

【构图与运镜】
镜头类型: 仰角全景 (仰视轮子)
镜头角度: 枆低仰角 (极低角度)
焦点: 轮椅轮子剪影,边缘光
景深: 浅, 背景虚化

【画面描述】
仰角极低位置拍摄, 画面底部是破旧木轮椅的轮子剪影. 青灰色的边缘光勾勒出轮椅轮廓——生锈的铁轮反射微弱冷光, 木纹细节若隐若现. 大部分画面被黑暗占据, 只有轮椅轮廓被冷光照亮. 神秘压抑的氛围, 落魄贵族的危险气息.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C, #1A1A2E)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 边缘光勾勒轮廓,对比度: 高
【画面质感】
- 景深: 浅, 背景虚化
- 细节: 齿纹、木纹, 病态苍白
- 质感: 神秘压抑, 电影质感
```
---

## 关键视觉参考
```
【构图要点】
- 极低仰角拍摄
- 轮椅轮子占据前景
- 大面积黑暗, 剪影效果

【光影要点】
- 随时间推进会逐渐展现沈清起
- 边缘光勾勒剪影
```
