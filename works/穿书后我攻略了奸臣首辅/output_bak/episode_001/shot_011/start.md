# Shot 011 - 首帧图片生成提示词
> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词
```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 剑拔弩张

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的空间, 仅有一盏青铜油灯摇曳. 冷青色主导, 阴影深重. 斑驳土墙, 腐朽木梁.

【角色设定】
沈清起, 22岁左右的年轻男子, 落魄贵族. 苍白如纸的病态白肤色, 棱角分明的面容, 狭长凤眼微微眯起, 目光若有所思, 正在权衡. 黑色长发束起, 身穿玄色锦袍. 坐在轮椅上, 长剑略微放低.

【构图与运镜】
镜头类型: 特写 (close up)
镜头角度: 仰角 (low angle)
焦点: 沈清起的脸
景深: 浅, 背景高度虚化

【画面描述】
仰角特写构图. 沈清起微微眯起眼睛, 目光若有所思, 正在权衡辛月影的话. 嘴角微微抿紧, 面无表情. 长剑在画面边缘可见, 略微放低. 冷青色主导, 阴影深重. 思索权衡的状态.

【色调与光影】
主色调: 冷青色主导 (#3A4A5C), 暗金色 (#8B7355)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 冷青色主导
对比度: 高

【画面质感】
- 景深: 浅, 面部清晰
- 细节: 眯起的凤眼, 思索表情
- 质感: 思索权衡, 电影质感
```
---

## 关键视觉参考
```
【构图要点】
- 仰角特写
- 微微眯起的眼睛
- 思索权衡的状态
【情绪暗示】
- 从思索到冷酷的转折即将发生
```
