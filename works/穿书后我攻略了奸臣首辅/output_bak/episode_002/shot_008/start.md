# Shot 008 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 危机化解

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁, 破损的窗棂和门框. 冷青灰色调为主, 暖黄烛光点缀. 破旧木门半开.

【角色设定】
沈清起, 22岁中国古代男子, 坐在画面右侧的破旧木制轮椅上. 苍白病态的面容, 狭长凤眼, 目光冷漠. 黑色长发略显凌乱. 身穿玄色交领长袍. 他的右手掌心有伤口, 血迹已干. 他正冷漠地注视前方.

辛月影, 18岁中国古代女子, 站在画面中央, 沈清起身旁. 精致娇美的五官, 白皙透亮的皮肤, 杏眼. 乌黑如墨的长发及腰. 身穿月白色对襟短襦配淡粉色百褶裙. 她镇定地站着, 表情带着一丝警觉, 似乎在等待什么.

霍齐, 35岁中国古代男子, 正从门外奔回, 位于画面左侧边缘. 魁梧健壮的身材, 古铜色皮肤. 方脸轮廓粗犷, 圆眼炯炯有神且愤怒, 浓密剑眉, 络腮胡. 粗黑短发以深色布巾束起. 身穿深褐色短打, 腰系粗布腰带, 手里拎着一把弓箭. 他愤怒地快步奔回, 表情充满敌意.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 平视 (eye level)
焦点: 三人互动
景深: 中等

【画面描述】
中景镜头, 展现三人在房间内的布局. 沈清起坐在画面右侧的轮椅上, 表情冷漠. 辛月影镇定地站在画面中央, 在沈清起身旁. 霍齐正从门外愤怒地奔回, 位于画面左侧边缘, 手里拎着弓箭, 表情愤怒充满敌意. 烛光在三人之间摇曳, 形成复杂的明暗对比. 整体画面充满紧张感, 危机即将来临.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 褐色 (#5D4037), 淡粉衣裙 (#FFD6E0)
布光方式: 烛光照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 三人表情和姿态
- 质感: 紧张危机感, 电影质感
```
