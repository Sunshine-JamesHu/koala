# Shot 002 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 内心挣扎

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀. 背景虚化处理, 突出人物.

【角色设定】
沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上. 苍白如纸的病态白皙皮肤, 轮廓分明的棱角坚毅面容. 狭长凤眼, 眼眶微陷, 目光阴鸷深邃, 凤眼半阖. 剑眉斜飞入鬓, 眉宇间带着阴郁. 嘴唇淡薄苍白, 嘴角冷峻. 黑色长发略显凌乱披散. 身穿玄色交领长袍. 他的右手在画面下方, 紧捏着一块锋利的碎瓷片, 指尖用力到发白. 整体呈现落魄贵族的气质, 阴郁冷酷.

【构图与运镜】
镜头类型: 特写 (close-up)
镜头角度: 平视 (eye level)
焦点: 面部, 特别是眼睛
景深: 浅, 背景虚化

【画面描述】
特写镜头, 聚焦在沈清起的面部. 他坐在轮椅上, 凤眼半阖, 目光阴冷地凝视前方. 苍白病态的面容在烛光下显得更加阴郁, 眼窝处投下深沉的阴影. 眉宇间没有波澜, 仿佛不为外界所动. 他的右手在画面下方隐约可见, 紧捏着一块锋利的碎瓷片, 指尖用力到发白. 整体呈现冷酷、阴鸷、不可捉摸的状态.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574)
布光方式: 单光源烛光侧面照明, 眼窝处形成深沉阴影
对比度: 高

【画面质感】
- 景深: 浅, 面部清晰, 背景虚化
- 细节: 眼神光, 凤眼的锐利, 苍白皮肤
- 质感: 阴郁压抑, 电影质感
```

## 关键视觉参考

```
【构图要点】
- 面部特写, 突出表情
- 凤眼半阖, 目光阴冷
- 苍白病态的面容

【光影要点】
- 烛光侧面打光
- 眼窝处深沉阴影
- 增强阴郁气质

【表情要点】
- 冷酷面无表情
- 眉宇间无波澜
- 嘴角冷峻
```
