# Shot 012 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 意外相遇

【场景环境】
古代边陲小镇外的夜色小路, 夜晚. 崎岖的小路, 两侧是荒芜的野地. 月光从云层中透出, 在地面投下斑驳光影. 冷蓝色调为主. 寒风萧瑟.

【角色设定】
辛月影, 18岁中国古代女子, 正在夜色中奔跑. 精致娇美的五官, 白皙透亮的皮肤, 杏眼惊恐. 乌黑如墨的长发在奔跑中飞舞. 身穿月白色对襟短襦配淡粉色百褶裙, 衣裙在奔跑中飘动. 她正在快速奔跑, 表情惊慌失措, 逃离破旧房屋的方向.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 平视 (eye level)
焦点: 奔跑中的辛月影
景深: 中等

【画面描述】
中景镜头, 辛月影在夜色的小路上奔跑. 她的身影在冷蓝的月光下显得单薄而仓皇, 淡粉色衣裙在身后飘动, 黑色长发飞舞. 她的表情惊慌失措, 杏眼惊恐, 正在逃离危险. 月光在她脸上投下斑驳的光影, 背景是模糊的荒野和远处小镇的轮廓. 整体画面呈现惊慌逃命的紧迫感.

【色调与光影】
主色调: 冷蓝色 (#1E272E)
点缀色: 月光 (#BDC3C7), 淡粉衣裙 (#FFD6E0)
布光方式: 月光照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 奔跑姿态, 惊恐表情
- 质感: 惊慌逃命, 电影质感
```
