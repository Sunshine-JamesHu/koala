# Shot 003 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 命令下达

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁, 破损的窗棂和门框. 冷青灰色调为主, 暖黄烛光点缀. 破旧木门半开, 门缝透入微弱的月光.

【角色设定】
沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上. 苍白如纸的病态白皙皮肤, 轮廓分明的面容. 狭长凤眼, 目光阴鸷冷峻, 正在侧过脸看向门外方向. 剑眉斜飞入鬓, 嘴唇淡薄苍白, 正准备开口发出命令. 黑色长发略显凌乱. 身穿玄色交领长袍. 整体呈现冷酷威严的姿态.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 低角度仰拍 (low angle)
焦点: 沈清起
景深: 中等, 背景适度虚化

【画面描述】
中景镜头, 沈清起坐在画面左侧的破旧轮椅上. 他正在侧过脸, 目光冷峻地看向门外方向. 苍白病态的面容在烛光下显得更加阴郁威严. 他的嘴唇微动, 正准备发出简短的命令. 背景是昏暗的房间和半开的木门, 门外透入微弱的月光. 低角度仰拍增强了他的威严感和压迫感.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 门外月光 (#BDC3C7)
布光方式: 烛光主光源, 门外月光辅光
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 沈清起的冷酷表情, 轮椅细节
- 质感: 威严压迫感, 电影质感
```

```
- 低角度仰拍增强威严

【光影要点】
- 烛光从侧面打来
- 门外月光形成冷暖对比
- 增强冷酷威严感

【表情要点】
- 冷酷威严
- 嘴唇微动准备命令
- 凤眼冷峻看向门外
```
