# Shot 010 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 被逐

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀.

【角色设定】
辛月影, 18岁中国古代女子, 站在沈清起身旁. 精致娇美的五官, 白皙透亮的皮肤, 杏眼. 乌黑如墨的长发及腰, 梳半扎半散的少女发式. 身穿月白色对襟短襦配淡粉色百褶裙, 外面还有一件淡青色外衣. 她正准备将外衣脱下, 表情温柔顺从, 眼神低垂.

沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上. 苍白病态的面容, 狭长凤眼, 目光冷漠. 黑色长发略显凌乱. 身穿玄色交领长袍. 他的右手缠着白色布条, 放在轮椅扶手上. 他冷漠地注视着辛月影.

【构图与运镜】
镜头类型: 中景 (medium)
镜头角度: 平视 (eye level)
焦点: 两人互动
景深: 中等

【画面描述】
中景镜头, 辛月影站在沈清起身旁, 正准备将淡青色外衣脱下. 她的表情温柔顺从, 眼神低垂, 似乎在关心沈清起的身体状况. 沈清起坐在轮椅上, 冷漠地注视着她, 凤眼中没有丝毫感情. 他的右手缠着白色布条, 放在扶手上. 烛光在两人之间摇曳, 形成冷暖对比. 整体画面呈现辛月影温柔关心与沈清起冷漠拒绝的对比.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 淡青外衣 (#B8D4E3)
布光方式: 烛光照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 辛月影温柔表情, 沈清起冷漠目光
- 质感: 关心与拒绝对比, 电影质感
```
