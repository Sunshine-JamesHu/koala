# Shot 001 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 生死博弈

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁, 破损的窗棂. 冷青灰色调为主, 暖黄烛光点缀, 形成强烈的冷暖对比. 破旧木制轮椅隐约可见于画面左侧阴影中.

【角色设定】
辛月影, 18岁中国古代女子, 站立姿态. 精致娇美的五官, 白皙透亮的皮肤, 杏眼清亮灵动, 柳叶眉纤细自然, 樱桃小口唇色淡粉. 乌黑如墨的长发及腰, 梳半扎半散的少女发式, 额前有轻薄的碎刘海. 身穿月白色对襟短襦配淡粉色百褶裙, 素雅朴素. 她站在画面右侧, 身体微微前倾, 眼神中带着急切和真诚, 正准备开口说服沈清起. 表情情真意切, 眉头微微皱起.

【构图与运镜】
镜头类型: 中近景 (medium close-up)
镜头角度: 平视 (eye level)
焦点: 辛月影面部
景深: 中等, 背景适度虚化

【画面描述】
中近景镜头, 辛月影站在画面右侧, 身体微微前倾做出恳求的姿态. 她的表情情真意切, 眉头微微皱起, 眼神中带着急切和一丝委屈, 仿佛在赌上性命说服对方. 烛光从画面左侧打来, 在她脸上形成明暗对比, 一侧明亮一侧隐入阴影. 淡粉色衣裙在昏暗中显得格外清丽. 背景是昏暗的破旧房间, 轮椅的轮廓隐约可见于左侧阴影中.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 淡粉色衣裙 (#FFD6E0)
布光方式: 单光源烛光侧面照明, 强烈的明暗对比
对比度: 高

【画面质感】
- 景深: 中等, 面部清晰, 背景适度虚化
- 细节: 眼神光、发丝、衣裙褶皱
- 质感: 电影质感, 戏剧性光影
```
