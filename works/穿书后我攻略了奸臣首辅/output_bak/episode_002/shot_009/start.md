# Shot 009 - 首帧图片生成提示词

> 可使用上一分镜的尾帧作为首帧

---

## 完整提示词

```
【图片基本信息】
比例: 16:9
风格: 古风动漫, 电影质感, 忠仆哀痛

【场景环境】
古代边陲小镇破旧房屋内部, 夜晚. 昏暗压抑的房间, 角落有一盏青铜油灯发出微弱的暖黄色光芒. 斑驳的土墙, 腐朽的木梁. 冷青灰色调为主, 暖黄烛光点缀.

【角色设定】
霍齐, 35岁中国古代男子, 正在跪下. 魁梧健壮的身材, 古铜色皮肤. 方脸轮廓粗犷, 圆眼炯炯有神且担忧, 浓密剑眉, 络腮胡. 粗黑短发以深色布巾束起. 身穿深褐色短打. 他正在跪到沈清起身前, 手里拿着布条, 准备为他包扎伤口. 表情担忧和心疼.

沈清起, 22岁中国古代男子, 坐在破旧木制轮椅上, 位于画面右侧. 苍白如纸的病态白皙皮肤, 狭长凤眼, 目光阴郁. 剑眉微蹙. 黑色长发略显凌乱. 身穿玄色交领长袍. 他的右手伸向霍齐, 掌心有碎瓷造成的伤口, 血迹触目. 他正准备让霍齐包扎.

【构图与运镜】
镜头类型: 中近景 (medium close-up)
镜头角度: 平视 (eye level)
焦点: 霍齐和沈清起的互动
景深: 中等

【画面描述】
中近景镜头, 霍齐正在跪到沈清起身前. 魁梧的身影跪下的姿态充满忠诚和恭敬. 他手里拿着布条, 表情担忧和心疼, 准备为沈清起包扎手上的伤口. 沈清起坐在轮椅上, 右手伸向霍齐, 掌心的伤口和血迹清晰可见. 他的表情阴郁, 凤眼中带着复杂的情绪. 烛光在两人之间摇曳, 营造出忠诚和哀痛的氛围.

【色调与光影】
主色调: 冷青灰色 (#3A4A5C)
点缀色: 暖黄烛光 (#D4A574), 褐色 (#5D4037)
布光方式: 烛光照明
对比度: 高

【画面质感】
- 景深: 中等
- 细节: 霍齐跪下的姿态, 沈清起伸出的手
- 质感: 忠诚哀痛, 电影质感
```
