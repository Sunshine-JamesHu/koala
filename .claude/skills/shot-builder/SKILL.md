# AI镜头构建师 (Shot Builder)

## 角色定位

镜头构建师是整个工作流的**核心技能**，负责将分镜脚本转化为可直接使用的制作包。每个镜头独立成文件夹，包含视频提示词、图片提示词和傻瓜式操作手册。

## 核心职责

1. **为每个镜头生成 video_prompt.md** — 可灵视频提示词
2. **为每个镜头生成 first_frame.md** — 首帧图片提示词
3. **为每个镜头生成 last_frame.md** — 尾帧图片提示词
4. **为每个镜头生成 storyboard_grid.md** — 9分镜组合图提示词
5. **为每个镜头生成 guide.md** — 傻瓜式操作手册
6. **生成章节审核报告 review.md** — 质量审核

## 前置依赖

### 必须读取
1. **风格配置**: `works/[剧名]/style.json`（必须，用于风格统一）
2. **分镜脚本**: `works/[剧名]/output/chapter_XXX/storyboard.md`（必须）
3. **角色参考**: `works/[剧名]/output/character/*.md`（相关角色）
4. **场景参考**: `works/[剧名]/output/scene/*.md`（相关场景）

### 风格配置读取（非常重要）⭐⭐⭐

**必须先读取** `works/[剧名]/style.json` 获取以下字段：

| 字段 | 用途 |
|------|------|
| `prompts.video_kling.style_prefix` | 视频提示词开头 |
| `prompts.video_kling.style_suffix` | 视频提示词结尾 |
| `prompts.video_kling.quality_tags` | 质量标签 |
| `prompts.image.style_prefix` | 图片提示词开头 |
| `prompts.image.style_suffix` | 图片提示词结尾 |
| `prompts.image.quality_tags` | 图片质量标签 |
| `prompts.image.negative_prompt` | 图片负向提示词 |
| `voice_settings` | 角色音色配置 |
| `visual_style.keywords` | 视觉风格关键词 |

## 工作流程

### 步骤1: 读取依赖文件

1. 读取 `style.json` 获取风格配置
2. 读取 `storyboard.md` 获取镜头列表
3. 读取相关角色的 `.md` 文件
4. 读取相关场景的 `.md` 文件

### 步骤2: 为每个镜头创建制作包

对于分镜脚本中的每个镜头：

1. **创建镜头文件夹**: `shot_XXX/`
2. **生成 video_prompt.md**: 可灵视频提示词（500-950字）
3. **生成 first_frame.md**: 首帧图片提示词
4. **生成 last_frame.md**: 尾帧图片提示词
5. **生成 storyboard_grid.md**: 9分镜组合图提示词
6. **生成 guide.md**: 傻瓜式操作手册

### 步骤3: 维护镜头连续性链

```
shot_001.last_frame → shot_002.first_frame → shot_002.last_frame → shot_003.first_frame → ...
```

- 每个镜头的尾帧 = 下一个镜头的首帧（视觉衔接）
- 第一个镜头的首帧由分镜脚本定义
- 最后一个镜头的尾帧由分镜脚本定义

### 步骤4: 生成审核报告

完成所有镜头后，生成 `review.md` 审核报告，检查：
- 风格一致性
- 镜头连续性
- 角色一致性
- 场景一致性
- 提示词质量

## 设计原则

1. **风格统一优先**: 所有提示词必须使用 style.json 中的风格标签
2. **傻瓜式操作**: guide.md 必须让用户无需思考就能操作
3. **镜头连续性**: 维护首尾帧衔接链
4. **质量优先**: 宁可慢一点，也要确保每个镜头的质量
5. **独立完整**: 每个镜头文件夹包含该镜头所需的一切
