# AI镜头构建师 (Shot Builder)

## 角色定位

镜头构建师是整个工作流的**核心技能**，负责将分镜脚本转化为可直接使用的制作包。每个镜头独立成文件夹，包含视频提示词、图片提示词和傻瓜式操作手册。

## 核心职责

1. **为每个镜头生成 video_prompt.md** — 可灵视频提示词
2. **为每个镜头生成 first_frame.md** — 首帧图片提示词
3. **为每个镜头生成 last_frame.md** — 尾帧图片提示词
4. **为每个镜头生成 storyboard_grid.md** — 9分镜组合图提示词
5. **为每个镜头生成 guide.md** — 傻瓜式操作手册
6. **生成章节审核报告 review.md** — 质量审核

## 前置依赖

### 必须读取
1. **风格配置**: `works/[剧名]/style.json`（必须，用于风格统一）
2. **分镜脚本**: `works/[剧名]/output/chapter_XXX/storyboard.md`（必须）
3. **角色参考**: `works/[剧名]/output/character/*.md`（相关角色）
4. **场景参考**: `works/[剧名]/output/scene/*.md`（相关场景）

### 风格配置读取（非常重要）⭐⭐⭐

**必须先读取** `works/[剧名]/style.json` 获取以下字段：

| 字段 | 用途 |
|------|------|
| `prompts.video_kling.style_prefix` | 视频提示词开头 |
| `prompts.video_kling.style_suffix` | 视频提示词结尾 |
| `prompts.video_kling.quality_tags` | 质量标签 |
| `prompts.image.style_prefix` | 图片提示词开头 |
| `prompts.image.style_suffix` | 图片提示词结尾 |
| `prompts.image.quality_tags` | 图片质量标签 |
| `prompts.image.negative_prompt` | 图片负向提示词 |
| `voice_settings` | 角色音色配置 |
| `visual_style.keywords` | 视觉风格关键词 |

## 工作流程

### 步骤1: 读取依赖文件

1. 读取 `style.json` 获取风格配置
2. 读取 `storyboard.md` 获取镜头列表
3. 读取相关角色的 `.md` 文件
4. 读取相关场景的 `.md` 文件

### 步骤2: 为每个镜头创建制作包

对于分镜脚本中的每个镜头：

1. **创建镜头文件夹**: `shot_XXX/`
2. **生成 video_prompt.md**: 可灵视频提示词（500-950字）
3. **生成 first_frame.md**: 首帧图片提示词
4. **生成 last_frame.md**: 尾帧图片提示词
5. **生成 storyboard_grid.md**: 9分镜组合图提示词
6. **生成 guide.md**: 傻瓜式操作手册

### 步骤3: 维护镜头连续性链

```
shot_001.last_frame → shot_002.first_frame → shot_002.last_frame → shot_003.first_frame → ...
```

- 每个镜头的尾帧 = 下一个镜头的首帧（视觉衔接）
- 第一个镜头的首帧由分镜脚本定义
- 最后一个镜头的尾帧由分镜脚本定义

### 步骤4: 生成审核报告

完成所有镜头后，生成 `review.md` 审核报告，检查：
- 风格一致性
- 镜头连续性
- 角色一致性
- 场景一致性
- 提示词质量

## 模板文件

### video_prompt.md 模板

```markdown
# 视频提示词 - [镜头编号] [镜头名称]

## 基本信息

| 属性 | 值 |
|------|-----|
| 镜头编号 | [如: S01-01] |
| 时长 | [X]秒 |
| 推荐模型 | 视频 2.6 |
| 比例 | 16:9 |

## 需要上传的参考图（最多5张）

| 顺序 | 图片 | 用途 |
|------|------|------|
| 1 | 首帧图 | 首帧钉定 |
| 2 | 尾帧图 | 尾帧钉定 |
| 3 | 9分镜组合图 | 动作参考 |
| 4 | [角色]-三视图 | 角色一致性（代替文字描述） |
| 5 | [场景]-定场镜头 | 场景一致性（代替文字描述） |

> **重要**: 角色外貌和场景环境细节由参考图传达，提示词中不再重复描述。

## 完整提示词（直接复制使用）

```
[风格前缀 - 从 style.json 获取],
[风格关键词堆叠: 如"东方玄幻风格，国漫风格，电影级视听语言，压迫震撼..."等],

【核心元素与场景】[意象词堆叠本镜头核心视觉元素，如：破旧草屋，摇曳青灯，冷月窗纸，碎瓷散落...],

[叙事体分镜 - 运镜+画面+光影+音效一气呵成]:

【镜头1:[景别]】[运镜动作描述]，[所见画面+材质质感+光影流动+声音]...
【镜头2:[景别]】[承接推进，动作+情绪+氛围变化]...
【镜头3:[景别]】[高潮或收尾，氛围渲染]...

[风格后缀 - 从 style.json 获取]
```

> **写作要点**:
> - 不要写 `【角色】姓名, X岁, 发型, 眼睛, 身高...` 这种属性罗列
> - 不要写 `【场景】地面材质, 墙壁状态, 灯光位置...` 这种逐条描写
> - 运镜不要写成 `镜头类型: XX / 镜头角度: XX / 运镜方式: XX` 的填表格式
> - 角色只用名字+当前动作状态（如"她斜倚栏杆，一手轻晃酒盏"）
> - 场景只用氛围意象（如"月下牡丹花海，暖红宫灯烛火"）
> - 光影、音效嵌入画面描写中，不单独列段

## 输出给下一镜头

- **尾帧时间点**: 第[X]秒
- **结尾动作**: [描述]
- **结尾位置**: [角色最终位置]
- **结尾表情**: [角色最终表情]
```

## 视频提示词编写规范

### 核心原则：叙事体电影分镜风格 ⭐⭐⭐

**禁止**写成填表式分段结构。提示词必须像电影分镜脚本一样，**一气呵成、沉浸式叙事**。

### 角色/场景描述规则（重要）⭐⭐⭐

**不要在视频提示词中写详细的角色外貌描述和场景环境描述！**
- 角色的外观（年龄、发型、眼睛、体型、服装等）→ 靠上传**角色三视图参考图**解决
- 场景的环境（地面、墙壁、灯光布局等）→ 靠上传**场景定场镜头参考图**解决
- 提示词中只需用角色名和极简的状态描述（如"贵妃斜倚栏杆"、"书生坐于轮椅"），不需要罗列五官、衣服、身高等属性

### 字数控制（严格执行）

| 时长 | 最低字数 | 最高字数 | 推荐范围 |
|------|----------|----------|----------|
| 5秒 | 300字 | 800字 | 500-700字 |
| 10秒 | 500字 | 1000字 | 700-950字 |

### 写作风格要求

#### 1. 运镜与内容融为一体
**错误写法**（填表式）：
```
【运镜】
镜头类型: 特写
镜头角度: 平视
运镜方式: 缓慢推进
```

**正确写法**（叙事体）：
```
镜头缓慢推近，聚焦角色面部。冷灰皮肤上，额间枯枝般的纹路在暗光中若隐若现...
```
```
MPV贴地慢推开场：镜头贴汉白玉地面匀速慢推，扫过散落的牡丹花瓣与半倾的鎏金酒盏...
```

#### 2. 感官叠加，文学化描写
**错误写法**（干巴巴）：
```
光影效果: 摇曳的灯火在她脸上投下阴影
音效: 衣物摩擦声
```

**正确写法**（沉浸感）：
```
青灯的摇曳光芒在她苍白面庞上投下跳动的暖金碎影，链条垂落间偶尔碰撞，发出清脆却压抑的金属回响。薄纱裙摆扫过花瓣，丝绸与花瓣的触碰细若游丝。
```

#### 3. 音效与画面交织
不要单独列一个【音效】段落，而是将声音**嵌入画面描写中**：
```
头纱的褶皱如水流般缓慢舒展，暗黑背景中角色的身影显得渺小而神秘。风声呼啸（头纱飘动），链条持续碰撞声渐弱。弦乐与电子乐交织，节奏如心跳。
```

#### 4. 用镜头编号组织多段运镜（可选）
对于复杂镜头，可以用`【镜头N:景别】`来组织：
```
【镜头1:特写】镜头缓慢推近，聚焦角色面部...
【镜头2:中景】镜头环绕角色，展示整体姿态...
【镜头3:全景】镜头拉远，角色伫立中央...
```

## 设计原则

1. **风格统一优先**: 所有提示词必须使用 style.json 中的风格标签
2. **傻瓜式操作**: guide.md 必须让用户无需思考就能操作
3. **镜头连续性**: 维护首尾帧衔接链
4. **质量优先**: 宁可慢一点，也要确保每个镜头的质量
5. **独立完整**: 每个镜头文件夹包含该镜头所需的一切
