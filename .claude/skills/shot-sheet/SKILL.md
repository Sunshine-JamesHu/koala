# 分镜提示词生成技能

## 触发方式
当用户要求生成分镜提示词、生成分镜Markdown时触发此技能。

## 数据来源

读取Agent生成的四个JSON文件：
- `scripts/episode_XXX/storyboard.json` - 分镜脚本
- `scripts/episode_XXX/keyframes.json` - 关键帧信息
- `scripts/episode_XXX/camera_work.json` - 运镜信息
- `scripts/episode_XXX/video_prompts.json` - 视频提示词

读取角色设定：
- `assets/characters/{角色名}/character.json`

## 输出结构

```
output/episode_XXX/
├── README.md           # 索引和全局风格
├── shot_001.md         # 第1个分镜
├── shot_002.md         # 第2个分镜
└── ...
```

## 提示词生成规则

### 三帧差异化

**首帧**：
- 如果是推镜头，镜头稍远一些
- 表情展示情绪的起始状态
- 描述分镜开始瞬间的画面

**关键帧**：
- 最具代表性的画面
- 表情展示情绪的高潮
- 角度、构图最标准

**尾帧**：
- 如果是推镜头，镜头更近
- 表情展示情绪的结束/转变状态
- 为下一分镜做铺垫

### 提示词要求

1. **首帧/尾帧/关键帧**：每条至少120字，描述准确详细
2. **视频提示词**：至少160字，包含完整信息
3. **风格统一**：每条提示词末尾附加全局风格词
4. **表情变化**：三帧的表情要有变化过渡

## 示例

用户: "生成episode_001的分镜Markdown"

Agent应该:
1. 读取 `scripts/episode_001/` 下的四个JSON文件
2. 读取角色设定文件
3. 理解剧情和角色特点
4. 为每个分镜生成有语义差异的三帧提示词
5. 生成README.md和所有shot_XXX.md文件
