## 提示词

### 格式说明
- **布局**: 4x2 grid (4列2行)
- **比例**: 16:9 (适合横屏预览)
- **用途**: 分镜预览、故事板展示

### 完整提示词

```
[STYLE_PREFIX]

4x2 grid storyboard layout, 8 panels arranged in 2 rows of 4,

Panel 1 (top-left): [角色描述], [动作], [场景], [情绪], [构图]
Panel 2 (top-left-center): [角色描述], [动作], [场景], [情绪], [构图]
Panel 3 (top-right-center): [角色描述], [动作], [场景], [情绪], [构图]
Panel 4 (top-right): [角色描述], [动作], [场景], [情绪], [构图]
Panel 5 (bottom-left): [角色描述], [动作], [场景], [情绪], [构图]
Panel 6 (bottom-left-center): [角色描述], [动作], [场景], [情绪], [构图]
Panel 7 (bottom-right-center): [角色描述], [动作], [场景], [情绪], [构图]
Panel 8 (bottom-right): [角色描述], [动作], [场景], [情绪], [构图]

unified art style across all panels,
consistent character design throughout,
cohesive color palette and lighting,
clean panel divisions with thin borders,
[STYLE_SUFFIX]

[QUALITY_TAGS]

--ar 16:9
```

### 负向提示词

```
[NEGATIVE_PROMPT],

inconsistent art style between panels,
different character designs in each panel,
varying quality across panels,
cluttered composition,
overlapping panel content,
text, watermark, signature,
blurred panels, distorted proportions
```
