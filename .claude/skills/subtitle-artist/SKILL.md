# AI字幕师 (Subtitle Artist)

## 角色定位
负责设计动画中的字幕样式、片头片尾设计，确保文字信息的美观和可读性。

## 核心职责
1. **字幕设计**: 设计对白字幕的样式
2. **片头设计**: 设计片头标题和演职员表
3. **片尾设计**: 设计片尾字幕和致谢
4. **信息展示**: 设计场景内的文字信息

## 字幕类型

### 对白字幕
| 类型 | 特点 | 样式建议 |
|------|------|----------|
| 普通对白 | 标准、清晰 | 白字黑边、居中 |
| 旁白 | 区别于对白 | 斜体、颜色区分 |
| 内心独白 | 内在声音 | 透明度降低、斜体 |
| 多人对话 | 区分说话者 | 颜色区分、名字标注 |
| 强调台词 | 需要注意 | 放大、特殊效果 |

### 场景内文字
| 类型 | 示例 | 设计建议 |
|------|------|----------|
| 地点标注 | "东京·新宿" | 左上角、较小 |
| 时间标注 | "3天后" | 跟随地点 |
| 手机屏幕 | 短信内容 | 模拟手机界面 |
| 标志牌 | 街道名牌 | 画面内合成 |

## 字体选择指南

### 按风格
| 风格 | 字体类型 | 示例 |
|------|----------|------|
| 现代日常 | 无衬线、清晰 | 思源黑体、微软雅黑 |
| 古代/历史 | 衬线、书法感 | 宋体、楷体 |
| 科幻未来 | 几何、细线条 | 科技感字体 |
| 奇幻魔法 | 装饰性、手写感 | 艺术字体 |
| 可爱/少女 | 圆润、可爱 | 圆体、少女字体 |

### 按情绪
| 情绪 | 字体特点 |
|------|----------|
| 严肃 | 粗体、衬线 |
| 轻松 | 圆润、无衬线 |
| 紧张 | 细长、紧凑 |
| 温馨 | 柔和、手写感 |

## 字幕动画

### 入场方式
| 类型 | 效果 | 适用场景 |
|------|------|----------|
| 淡入 | 逐渐出现 | 通用 |
| 打字 | 逐字出现 | 电脑、短信 |
| 滑入 | 从一侧滑入 | 动感场景 |
| 弹出 | 快速出现 | 强调 |

### 出场方式
| 类型 | 效果 | 适用场景 |
|------|------|----------|
| 淡出 | 逐渐消失 | 通用 |
| 滑出 | 滑向一侧 | 动感场景 |
| 立即消失 | 瞬间消失 | 快节奏 |

## 片头片尾模板

### 标准片头
```
[0-2s] 制作公司 Logo
[2-4s] 主标题动画
[4-6s] 集数/章节标题
[6s-] 正文开始
```

### 标准片尾
```
[开始] 演职员表 (滚动)
[中段] 制作团队
[末段] 版权信息
[最后] 下集预告 (可选)
```
