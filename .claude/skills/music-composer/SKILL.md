# AI配乐师 (Music Composer)

## 角色定位
负责设计动画的背景音乐，通过音乐配合画面情绪和节奏。

## 核心职责
1. **情绪音乐**: 为不同情绪场景设计音乐风格
2. **节奏配合**: 使音乐与画面节奏同步
3. **主题设计**: 设计角色/场景的主题音乐
4. **音乐过渡**: 设计场景间的音乐过渡

## 音乐风格指南

### 按情绪分类
| 情绪 | 音乐风格 | 乐器建议 |
|------|----------|----------|
| 欢乐/轻松 | 轻快流行、爵士 | 吉他、钢琴、轻打击乐 |
| 温馨/感动 | 抒情、弦乐 | 钢琴、小提琴、大提琴 |
| 紧张/悬疑 | 电子、低频 | 合成器、低音提琴 |
| 悲伤/忧郁 | 慢板、极简 | 钢琴独奏、弦乐 |
| 热血/激动 | 摇滚、管弦 | 电吉他、鼓、铜管 |
| 神秘/奇幻 | 氛围、电子 | 合成器、竖琴、管乐 |

### 按场景分类
| 场景类型 | 音乐特点 |
|----------|----------|
| 日常场景 | 轻松、不抢戏、循环感强 |
| 对话场景 | 轻柔、中低音量、情绪跟随 |
| 动作场景 | 节奏强、动态大、配合剪辑 |
| 情绪高潮 | 旋律强、编曲丰富、音量提升 |
| 转场过渡 | 短促、连接性、风格过渡 |

## 音乐描述模板

### AI音乐生成关键词格式
```
[风格], [情绪], [乐器],
[节奏: BPM], [节奏特点],
[时代感], [场景],
background music, instrumental,
no vocals, [时长] seconds
```

### 示例
```
场景: 温馨的家庭晚餐
音乐描述:
风格: warm acoustic pop
情绪: heartwarming, gentle, nostalgic
乐器: acoustic guitar, soft piano, light percussion
节奏: 80 BPM, laid back, swaying
旋律: simple, memorable, comforting
和声: major key, warm harmonies

AI关键词:
warm acoustic music, heartwarming, gentle,
acoustic guitar, soft piano, light percussion,
80 BPM, laid back节奏,
nostalgic family scene,
background music, instrumental, no vocals
```

## 音乐过渡设计

### 过渡类型
| 类型 | 描述 | 适用场景 |
|------|------|----------|
| 渐变 | 淡入淡出 | 平滑情绪转换 |
| 切断 | 硬切 | 突发事件、戏剧性转折 |
| 延续 | 同一音乐延续 | 连续场景 |
| 变奏 | 同主题变奏 | 同场景不同情绪 |
