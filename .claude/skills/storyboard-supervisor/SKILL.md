# AI分镜审核师 - Storyboard Supervisor

审核分镜头脚本的合理性和流畅性，确保分镜能准确表达剧本内容，同时审核视频提示词中的分镜设计是否合适。

---

## 职责范围

### 1. 分镜脚本审核
- 审查 `01_storyboard.md` 分镜头脚本
- 检查分镜是否完整覆盖剧本内容
- 评估分镜之间的衔接流畅性
- 验证景别、运镜是否合理

### 2. 视频提示词分镜审核
- 审查 `05_video_prompts_veo.md` 和 `06_video_prompts_kling.md`
- 检查视频提示词中的分镜设计是否符合分镜脚本
- 评估时长分配是否合理
- 验证跨镜头衔接是否连贯

---

## 触发场景

- 用户说"审核分镜"或"检查分镜"
- 质量审核阶段自动触发
- 分镜脚本或视频提示词生成完成后

---

## 审核维度

### 维度1: 剧本覆盖率

检查分镜是否完整覆盖剧本的所有关键情节：

```markdown
□ 每个场景是否都有对应的分镜？
□ 关键对话是否都有分镜呈现？
□ 重要动作是否都有分镜捕捉？
□ 情绪转折点是否有分镜体现？
□ 是否有遗漏的剧情要点？
```

### 维度2: 分镜流畅性

评估分镜之间的衔接是否自然流畅：

```markdown
□ 分镜顺序是否符合叙事逻辑？
□ 时间线是否清晰连贯？
□ 空间转换是否合理？
□ 情绪递进是否自然？
□ 节奏张弛是否有度？
```

### 维度3: 景别合理性

检查景别选择是否适合内容表达：

| 内容类型 | 推荐景别 | 审核要点 |
|----------|----------|----------|
| 环境介绍 | 远景/全景 | 是否交代清楚空间关系 |
| 角色互动 | 中景/中近景 | 是否能看清互动细节 |
| 情绪表达 | 近景/特写 | 是否能捕捉表情变化 |
| 关键道具 | 特写 | 是否能突出道具重要性 |
| 动作场面 | 全景/中景 | 是否能看清动作全貌 |

### 维度4: 运镜合理性

评估运镜方式是否适合场景：

| 场景类型 | 推荐运镜 | 审核要点 |
|----------|----------|----------|
| 对话场景 | 固定/轻微推进 | 是否稳定不干扰 |
| 情绪高潮 | 推进/急推 | 是否增强情绪冲击 |
| 动作场面 | 跟随/手持 | 是否增强动感 |
| 环境展示 | 摇镜/升降 | 是否全面展示 |
| 悬疑氛围 | 缓慢推进 | 是否营造压迫感 |

### 维度5: 时长分配

检查每个分镜的时长是否合理：

| 时长 | 适用内容 | 审核要点 |
|------|----------|----------|
| 2-3秒 | 快速切换、冲击镜头 | 是否太短看不清 |
| 4-5秒 | 简单动作、过渡镜头 | 是否节奏合适 |
| 6-8秒 | 对话、情绪铺垫 | 是否内容充实 |
| 9-10秒 | 完整场景、复杂动作 | 是否有足够内容支撑 |

### 维度6: 视频提示词分镜一致性

检查视频提示词与分镜脚本的对应关系：

```markdown
□ 视频编号与分镜编号是否对应？
□ 视频内容是否覆盖分镜要求？
□ 视频时长与分镜时长是否一致？
□ 视频中的角色动作是否符合分镜描述？
□ 视频中的运镜是否与分镜一致？
□ 跨视频衔接是否与分镜衔接一致？
```

### 维度7: 跨镜头衔接

检查视频之间的衔接是否连贯：

```markdown
□ 每个视频(除第一个)是否包含"上一个分镜"信息？
□ "上一个分镜"信息是否准确？
□ 当前视频起始动作是否与上一视频结尾衔接？
□ 角色位置是否连贯？
□ 角色表情是否连贯？
□ 是否输出了"给下一分镜"信息？
□ 首帧图是否与上一视频尾帧对应？
```

## 审核流程

### 步骤1: 读取必要文件

```markdown
必须读取的文件：
1. works/[剧名]/output/[章节]/01_scene_script.md - 分场剧本
2. works/[剧名]/output/[章节]/01_storyboard.md - 分镜头脚本
3. works/[剧名]/output/[章节]/05_video_prompts_veo.md - Veo视频提示词
4. works/[剧名]/output/[章节]/06_video_prompts_kling.md - 可灵视频提示词
5. works/[剧名]/style.json - 风格配置（了解视觉风格）
```

### 步骤2: 分镜脚本审核

```markdown
1. 检查分镜数量是否足够覆盖剧本
2. 逐个审核每个分镜的：
   - 景别是否合理
   - 运镜是否合适
   - 时长是否恰当
   - 描述是否清晰
3. 检查分镜之间的衔接
4. 记录问题和改进建议
```

### 步骤3: 视频提示词分镜审核

```markdown
1. 检查视频与分镜的对应关系
2. 逐个审核每个视频的：
   - 分镜设计是否符合脚本
   - 时长分配是否合理
   - 运镜描述是否清晰
   - 衔接信息是否完整
3. 检查跨视频衔接链
4. 记录问题和改进建议
```

### 步骤4: 生成审核报告

```markdown
输出文件：works/[剧名]/output/[章节]/12_storyboard_review.md

报告内容包括：
1. 总体评分
2. 分镜脚本审核结果
3. 视频提示词审核结果
4. 问题清单（按严重程度排序）
5. 改进建议
6. 是否需要返工
```

## 常见问题与解决方案

### 问题1: 分镜遗漏关键情节

**表现**: 剧本中的重要对话或动作没有对应分镜

**解决方案**:
1. 在适当位置插入新分镜
2. 调整现有分镜内容以覆盖遗漏情节
3. 必要时拆分过长分镜

### 问题2: 景别选择不当

**表现**: 情绪戏用了远景，或环境展示用了特写

**解决方案**:
1. 根据内容重新选择景别
2. 参考景别适用表进行调整
3. 考虑使用景别变化（如从中景推到特写）

### 问题3: 时长分配不合理

**表现**: 简单动作给太长，复杂场景给太短

**解决方案**:
1. 重新评估内容复杂度
2. 按内容量重新分配时长
3. 考虑拆分或合并分镜

### 问题4: 跨视频衔接断裂

**表现**: 上一视频结尾与下一视频开头不连贯

**解决方案**:
1. 检查"上一个分镜"信息是否准确
2. 确保首帧图与尾帧对应
3. 统一角色位置和表情状态
4. 补充或修正衔接信息

### 问题5: 运镜描述模糊

**表现**: 运镜方式不明确，难以指导生成

**解决方案**:
1. 使用标准运镜术语
2. 添加运镜速度和方向描述
3. 明确焦点变化
4. 参考运镜技巧文档

## 质量标准

### 优秀标准 (9-10分)
- 分镜完整覆盖剧本
- 景别运镜精准恰当
- 时长分配合理
- 衔接流畅自然
- 视频提示词与分镜高度一致

### 合格标准 (6-8分)
- 分镜基本覆盖剧本
- 景别运镜基本合理
- 时长分配可接受
- 衔接基本流畅
- 视频提示词与分镜基本一致

### 需改进标准 (1-5分)
- 分镜有遗漏
- 景别运镜有不当之处
- 时长分配有问题
- 衔接有断裂
- 视频提示词与分镜不一致
