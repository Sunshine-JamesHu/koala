# 可灵表情演绎示例集

## 喜悦情绪

### 突然收到好消息（5秒）
```
生活剧风格，年轻女孩看着手机屏幕。
眉头微皱（疑惑）→ 眼睛一亮（惊喜）→ 嘴角忍不住上扬 → 欢呼雀跃。
镜头推进到脸部特写，柔和暖光。
突出：惊喜、纯真、喜悦。
```

### 重逢时刻（10秒）
```
电影风格，火车站出口。
年轻人四处张望（焦急）→ 看到目标后眼睛睁大（认出）→ 嘴角颤抖（激动）→ 冲上前拥抱（释然）。
镜头从中景推到近景，捕捉情绪变化。
突出：期待、激动、温情。
```

## 悲伤情绪

### 收到坏消息（5秒）
```
剧情片风格，中年男人接到电话。
表情僵硬（难以置信）→ 眼眶泛红（悲伤涌上）→ 眼神涣散（恍惚）→ 泪水无声滑落。
镜头静止特写，冷色调光。
突出：震惊、悲伤、无助。
```

### 目送离别（10秒）
```
文艺片风格，女子站在码头目送船离开。
强颜欢笑（掩饰不舍）→ 转身背对（不愿面对）→ 肩膀颤抖（情绪崩溃）→ 低头抹泪（释然接受）。
镜头侧后方中景，夕阳逆光。
突出：不舍、心碎、放手。
```

## 愤怒情绪

### 被背叛后（5秒）
```
悬疑片风格，角色发现真相。
表情凝滞（震惊）→ 眉头紧锁（压抑怒火）→ 眼神变狠（决意）→ 低声说出台词。
镜头缓慢推进到眼部特写，暗调光。
突出：压抑、愤怒、危险。
```

### 愤怒爆发（10秒）
```
剧情片风格，角色情绪积累到顶点。
咬紧牙关（忍耐）→ 青筋暴起（濒临爆发）→ 猛然拍桌（爆发）→ 怒吼（宣泄）。
镜头从固定到轻微震动配合情绪。
突出：压抑 → 爆发的张力。
```

## 恐惧情绪

### 意识到危险（5秒）
```
恐怖片风格，角色察觉异常。
动作停顿（警觉）→ 瞳孔微缩（恐惧初现）→ 呼吸变急（本能反应）→ 缓缓回头（面对恐惧）。
镜头固定，配合音效营造紧张。
突出：悬疑、恐惧临近。
```

### 濒临崩溃（10秒）
```
心理惊悚片风格，角色精神状态恶化。
手指颤抖（焦虑）→ 眼神游离（恍惚）→ 自言自语（崩溃边缘）→ 突然尖叫（彻底崩溃）。
镜头晃动增强不稳定感，冷蓝色调。
突出：精神崩溃、恐惧、绝望。
```

## 惊讶情绪

### 意外发现（5秒）
```
剧情片风格，角色发现隐藏的秘密。
随意翻看 → 动作停顿 → 眼睛睁大 → 嘴巴微张 → 倒吸冷气。
镜头从手部动作切到脸部特写。
突出：意外、震惊。
```

### 突然相遇（5秒）
```
都市剧风格，两人在街角偶遇。
低头走路 → 撞到人 → 抬头 → 愣住（认出）→ 眼神复杂。
镜头中景切近景，捕捉微妙变化。
突出：意外、复杂情感。
```

## 复合情绪

### 爱恨交织（10秒）
```
剧情片风格，角色面对曾经的爱人。
远远看见（怀念）→ 表情复杂（纠结）→ 想靠近又退缩（矛盾）→ 最终选择转身离开（决绝）。
镜头从中景推到表情特写再拉远。
突出：爱、恨、不舍、决绝的复杂。
```

### 希望与绝望（10秒）
```
灾难片风格，幸存者等待救援。
望向远方（期待）→ 时间流逝眼神黯淡（失望）→ 几乎放弃（绝望）→ 突然看到希望（重燃）。
镜头广角到特写，光线从暗转亮。
突出：期待 → 绝望 → 希望的情绪曲线。
```

## 微表情示例

### 隐藏真实想法（5秒）
```
政治剧风格，角色在谈判桌上。
面带微笑（表面）→ 眼神冰冷（真实）→ 轻微抿嘴（压抑）→ 恢复笑容（伪装）。
镜头特写微表情变化。
突出：表里不一、城府深沉。
```

### 忍住情绪（5秒）
```
职场剧风格，员工被批评。
低头承受（压抑）→ 眼眶泛红（委屈）→ 深呼吸调整（控制）→ 抬头微笑（掩饰）。
镜头从低角度仰拍增强压迫感。
突出：委屈、忍耐、职业素养。
```

## 情绪转换技巧

### 使用箭头连接
```
[状态A] → [触发事件] → [反应B] → [变化C] → [结果D]
```

### 添加身体语言
```
不只是面部表情，配合：
- 呼吸变化（急促、屏住、深呼吸）
- 肢体动作（握拳、颤抖、后退）
- 微动作（抿嘴、眨眼、歪头）
```

### 环境配合
```
情绪与环境呼应：
- 悲伤：冷色调、雨天、昏暗
- 喜悦：暖色调、阳光、明亮
- 恐惧：暗色调、阴影、冷风
```
