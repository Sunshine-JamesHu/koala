# 可灵动作场景示例集

## 追逐场景

### 城市跑酷（10秒）
```
电影大片风格，一个穿着黑色运动装的年轻人在城市屋顶间跑酷。
起步冲刺 → 蹬墙翻越 → 空中转体 → 落地翻滚缓冲 → 继续奔跑。
镜头高速跟随，低机位拍摄，周围景物因高速运动而动态模糊。
突出：速度感、自由感、危险与刺激。
```

### 街道追逐（10秒）
```
动作片风格，两名特工在雨夜的狭窄巷弄中追逐。
前方的特工快速转弯闪入小巷，后方追击者毫不犹豫地跟进。
两人跨过杂物、翻越围墙，雨水飞溅。
镜头手持感晃动，配合紧张节奏。
突出：紧迫感、危险氛围。
```

## 打斗场景

### 近身格斗（5秒）
```
格斗电影风格，两个黑衣人在昏暗仓库中对峙。
A先发制人出拳，B侧身闪避后反击，两人快速过招三回合。
镜头晃动配合动作节奏，动态模糊增强打击感。
突出：力量感、打击节奏。
```

### 武器对决（10秒）
```
武侠风格，两位剑客在竹林中对决。
月光下，双方持剑对峙。突然A发起攻击，剑光闪烁。
B格挡后反攻，两人剑刃相撞，火星四溅。
镜头360度环绕两人旋转，慢动作定格关键瞬间。
突出：武侠美学、剑意氛围。
```

## 跳跃场景

### 高空跳伞（10秒）
```
好莱坞大片风格，三名跳伞者从运输机舱门跃出。
自由落体阶段，身体在空中调整姿态，互相靠近。
云层快速掠过，阳光穿透云缝照射下来。
镜头跟随下落，偶尔切换到第一视角。
突出：高度感、自由感、震撼视觉。
```

### 楼宇跳跃（5秒）
```
动作片风格，特工从一栋楼顶跃向另一栋。
起跳瞬间身体前倾 → 空中伸展 → 抓住对面楼边缘 → 用力翻身上去。
镜头侧面跟随，捕捉空中的弧线轨迹。
突出：惊险刺激、身体控制力。
```

## 撞击场景

### 汽车碰撞（5秒）
```
电影大片风格，两辆车在路口高速相撞。
碰撞瞬间玻璃碎裂飞溅，车身变形，烟尘四起。
慢动作捕捉撞击细节，镜头震动效果。
突出：冲击力、破坏感、危险。
```

### 人摔落（5秒）
```
动作片风格，角色被击飞撞向墙壁。
身体撞击墙面发出闷响 → 顺势滑落 → 剧烈咳嗽着挣扎起身。
镜头轻微震动，配合撞击节奏。
突出：打击力度、疼痛感。
```

## 潜行场景

### 潜入建筑（10秒）
```
谍战风格，特工深夜潜入敌方建筑。
从天窗缓缓降落 → 静默落地 → 警惕地观察四周 → 快速穿过走廊。
镜头低角度跟随，偶尔切换到热成像视角。
突出：紧张感、专业性、危险氛围。
```

### 躲避追击（5秒）
```
悬疑片风格，角色躲在门后屏住呼吸。
追击者的脚步声越来越近 → 在门前停下 → 转身离去。
角色紧贴墙壁，汗水顺着脸颊滑落。
镜头特写面部表情，配合心跳音效。
突出：紧张压迫感、危险临近。
```

## 群体动作

### 人群穿越（10秒）
```
纪录片风格，主角在拥挤的人群中快速穿行。
身体侧身闪避 → 推开挡路的人 → 加速冲刺 → 冲出人群。
镜头手持跟随，略带晃动增强真实感。
突出：紧迫感、现实感。
```

### 团队配合（10秒）
```
动作片风格，三人战术小队进行室内突击。
破门而入 → 分散站位 → 交叉掩护 → 逐房间搜索。
镜头快速切换各队员视角，营造战术感。
突出：专业性、团队配合、紧张节奏。
```

## 动物动作

### 动物奔跑（5秒）
```
自然纪录片风格，猎豹在草原上全速奔跑。
身体肌肉线条分明，四肢协调运动，尾巴保持平衡。
镜头侧面跟随，背景虚化突出主体。
突出：速度、力量、自然之美。
```

### 飞行动作（10秒）
```
自然纪录片风格，老鹰从悬崖俯冲捕猎。
展翅滑翔 → 收翅俯冲 → 伸出利爪 → 拉起上升。
镜头跟随飞行轨迹，偶尔切换到老鹰第一视角。
突出：自由感、野性美、震撼视觉。
```
