## ⚠️ 风格统一要求（必须遵守）⭐⭐⭐

> **每个视频提示词必须使用 style.json 中的风格标签，确保全剧视觉风格统一！**

### 必须使用的风格字段

| 字段位置 | 用途 | 说明 |
|----------|------|------|
| **风格前缀** | 提示词开头 | 定义整体视觉风格，如：`古风动漫风格, 唯美国风, 精致细腻的动画质感` |
| **风格后缀** | 提示词结尾 | 强化风格，如：`精致细节, 柔和光影, 电影质感` |
| **质量标签** | 质量保证 | 如：`high quality, detailed, cinematic` |

### 风格统一检查清单

在生成每个视频提示词前，必须确认：

- [ ] **提示词以风格前缀开头** - 直接从 style.json 复制
- [ ] **提示词以风格后缀结尾** - 直接从 style.json 复制
- [ ] **所有视频使用相同的风格标签** - 不要随意修改
- [ ] **角色描述与图片提示词一致** - 使用 04_image_prompts.md 中的角色描述

### 风格不统一的常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 画风突变 | 未使用风格前缀 | 确保每个提示词都以风格前缀开头 |
| 角色外观变化 | 描述不一致 | 复制 04_image_prompts.md 中的角色描述 |
| 色调不统一 | 缺少风格后缀 | 添加风格后缀确保色调一致 |
| 质量不稳定 | 缺少质量标签 | 在提示词末尾添加质量标签 |

## 操作步骤总结

### 视频 2.6 音画同步模式（⭐最常用，推荐）
1. **准备图片**: 生成首帧图片和角色参考图
2. **选择模型**: 选择 **视频 2.6**
3. **选择时长**: 5秒 或 10秒
4. **复制提示词**: 复制"完整提示词"部分
5. **上传图片**: 按照图片清单顺序上传
6. **点击生成**: 等待音画同步输出
7. **保存文件**: 将视频按编号保存

### 分镜叙事模式（O1/3.0 Omni）
1. **准备图片**: 根据"需要上传的图片清单"生成所有角色和场景图片
2. **选择模型**: 选择 可灵3.0 Omni 或 O1
3. **创建主体**: 在可灵中上传图片，创建角色主体
4. **复制提示词**: 复制"完整提示词"到提示词输入框
5. **选择时长**: 选择10秒
6. **生成视频**: 点击生成，等待视频输出
7. **保存文件**: 将视频按片段编号保存
