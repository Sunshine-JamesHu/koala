# 可灵AI视频提示词 (Kling Prompter)

为快手可灵AI生成专业视频提示词，充分利用可灵 O1（最强模型）、3.0/3.0 Omni 的智能分镜、主体参考、音画同出和指令变换能力。

## 可灵模型版本选择（重要）

### 当前推荐模型

| 模型版本 | 定位 | 支持时长 | 核心优势 | 推荐场景 |
|----------|------|----------|----------|----------|
| **视频 2.6** ⭐最常用 | 音画同步专家 | **5秒 / 10秒** | 原生音画同出、对话/唱歌/音效/环境音 | 对白场景、氛围视频、需要声音的视频 |
| **可灵 O1 / 视频 O1** | 最强模型 | **5秒 / 10秒** | 全能引擎、全能指令、指令变换、全能参考 | 复杂场景、高精度需求、视频编辑 |
| **可灵3.0 / 3.0 Omni** | 智能分镜 | **5秒 / 10秒** | 主体参考、智能调度、分镜叙事 | 多镜头叙事、动作戏 |

> **重要提示**：所有模型最大时长均为 10秒。视频 2.6 是最常用的模型，专注于音画同步。

### 可灵 O1 五大亮点（最强模型特性）

1. **全能引擎** - 集成参考视频生成、文生视频、首尾帧、视频内容编辑、风格重绘于一体
2. **全能指令** - 图片、视频、主体、文字皆可作为指令，理解更精准
3. **指令变换** - 用文字指令直接编辑视频：去除路人、变换时间、更换服装等
4. **全能参考** - 多模态参考能力，支持图片、视频、主体同时使用
5. **世界模型** - 更强的物理世界理解能力

## 前置依赖

### ⚠️ 风格统一（最重要）⭐⭐⭐

**必须先读取** `works/[剧名]/style.json` 获取风格配置，并且**每个提示词都必须使用**这些风格标签！

**风格标签是确保全剧视觉统一的核心，不使用风格标签会导致：**
- 不同视频之间画风突变
- 角色外观在不同视频中不一致
- 色调和氛围不统一
- 整体观看体验割裂

**必须使用的字段**：
- `prompts.video_kling.style_prefix` - 风格前缀（**必须放在每个提示词的开头**）
- `prompts.video_kling.style_suffix` - 风格后缀（**必须放在每个提示词的结尾**）
- `prompts.video_kling.quality_tags` - 质量标签
- `visual_style.keywords` - 视觉风格关键词
- `color.mood` - 色彩情绪
- **`voice_settings`** - 角色音色配置（⭐重要，用于对话场景）

### 风格统一检查（生成每个提示词前必做）

```
□ 是否读取了 style.json？
□ 提示词是否以 style_prefix 开头？
□ 提示词是否以 style_suffix 结尾？
□ 角色描述是否与 04_image_prompts.md 一致？
□ 是否使用了相同的 quality_tags？
```

### 音色配置读取（重要）

从 `style.json` 的 `voice_settings` 中提取角色音色：

```json
"voice_settings": {
  "female_lead": {
    "name": "辛月影",
    "voice_type": "甜美清脆",
    "pitch": "中高音",
    "emotion_range": ["活泼", "俏皮", "惊恐", "委屈", "撒娇"]
  },
  "male_lead": {
    "name": "沈清起",
    "voice_type": "清冷低沉",
    "pitch": "低音",
    "emotion_range": ["冷漠", "阴鸷", "戏谑", "温柔", "痛苦"]
  }
}
```

**音色标签格式**：`【【@图片X】，角色名，声音特质 + 情绪 + 地说道】："台词内容"`

**正确示例**：
```
【【@图片1】，辛月影，甜美清脆、恐惧地说道】："你...你在说什么？"
【【@图片2】，沈清起，清冷低沉、阴冷地说道】："辛四娘，你自尽吧。"
```

**错误示例**（格式不正确）：
```
【辛月影，甜美清脆，恐惧】："..."  ← 缺少【@图片X】引用和"地说道"
【辛月影】：""  ← 完全缺少图片引用和音色信息
【【@图片1】，甜美清脆】："..."  ← 缺少角色名
```

## 提示词饱满度要求（重要）⭐⭐⭐

### 每个分镜必须包含的8个维度（严格）

**一个饱满的分镜描述必须包含以下8个元素，缺一不可：**

```markdown
分镜X：[开始时间]-[结束时间]秒，[景别]，[镜头运动]，

[1. 环境开场] 场景环境描写（光线、色调、背景细节、氛围元素）- 至少50字
[2. 角色位置] 角色在画面中的精确位置、姿态、朝向、与环境的距离关系
[3. 动作描述] 具体的动作过程（起始状态 → 动作过程 → 结束状态），包含身体各部位的动作细节
[4. 表情变化] 面部表情的层次化变化（A → B → C），包含眼睛、眉毛、嘴唇的细微变化
[5. 运镜细节] 运镜类型 + 运镜速度 + 焦点变化 + 转场方式（详见运镜章节）
[6. 声音元素] 对白/内心独白/音效/环境音（如有），使用标准格式
[7. 色调光影] 具体的色调描述、布光方式、对比度
[8. 情绪氛围] 整体情绪基调和画面暗示，对剧情的隐喻
```

### 分镜描述字数要求（严格执行）

| 时长 | 最低字数 | 推荐字数 | 必须维度 |
|------|----------|----------|----------|
| 2-3秒 | 150字 | 200-250字 | 8维度全部，环境可简化 |
| 4-5秒 | 200字 | 250-350字 | 8维度全部 |
| 6-8秒 | 300字 | 350-500字 | 8维度全部，动作细节更丰富 |
| 9-10秒 | 400字 | 500-700字 | 8维度全部，多层次描述 |

### 提示词总体长度要求（严格执行）⭐⭐⭐

**重要：提示词必须有字数下限和上限**

| 视频时长 | 最低字数（不含风格标签） | 最高字数 | 推荐字数 | 分镜数量 |
|----------|--------------------------|----------|----------|----------|
| 5秒 | ≥300字 | ≤800字 | 500-700字 | 1-2个分镜 |
| 10秒 | ≥500字 | ≤1000字 | 700-950字 | 2-4个分镜 |

**字数控制原则**：
1. **不能低于最低字数** - 确保提示词足够详细，包含所有必要维度
2. **不能超过最高字数** - 可灵系统限制，超过会导致生成失败
3. **推荐范围内最佳** - 既有足够细节控制画面，又不会超出系统限制

### 饱满度示例对比

❌ **过于简短（不合格，会被退回修改）**:
```
分镜1：0-4秒，中景，镜头固定，
辛月影坐在地上，环顾四周。
```
**问题诊断**：
- 环境描述缺失（无光线、色调、氛围）
- 角色位置不精确（"坐在地上"太模糊）
- 动作无过程（只有结果状态）
- 表情变化缺失
- 运镜细节缺失（无速度、焦点）
- 声音元素缺失
- 色调光影缺失
- 情绪氛围缺失
- 字数不足（仅20字，要求≥200字）

✅ **饱满详细（合格，可直接使用）**:
```
分镜1：0-4秒，中景，镜头缓慢下移后固定，

[1.环境开场] 破败草屋昏暗内景，满地碎瓷片在青灯光下泛着微弱光芒，墙角蛛网在穿堂风中轻轻摇曳，空气中弥漫着尘土与霉变的气息。一盏青铜油灯在角落摇曳，投下忽明忽暗的光影，月光从破损的窗纸透入，形成一道冷白色的光束指向地面中央。

[2.角色位置] 【@图片1】 辛月影趴伏在冰冷泥土地面的中央位置，身体呈侧卧姿态，头部枕在交叠的双臂上，面朝上方。她身穿破旧的青灰色粗布衣裳，打着深褐色补丁，衣角沾染了尘土。双螺髻有些散乱，几缕碎发垂落在脸侧，娇小的身躯在昏暗中显得格外脆弱。

[3.动作描述] 她的手指先是微微颤动，从指尖开始逐渐蔓延到整只手掌。随后睫毛轻颤，眼皮缓缓掀开一条缝隙，眼神从茫然逐渐聚焦。她用手肘撑起上半身，身体微微摇晃，另一只手揉了揉太阳穴，茫然地环顾四周。

[4.表情变化] 表情层次：睡梦中平静 → 睁眼时茫然 → 眼神逐渐聚焦 → 困惑皱眉 → 苦涩茫然。杏眼先是无神，随后瞳孔中逐渐有了焦距，眉心微微蹙起，嘴唇微微张开似乎想说什么却又咽了回去。

[5.运镜细节] 镜头从屋梁高度缓慢匀速下移（约2秒），掠过断裂的桌腿、散落的碎瓷，最终定格在辛月影身上（中景）。焦点从环境逐渐转移到角色面部，景深从深变浅，背景逐渐虚化。

[6.声音元素] 【环境音】深夜穿堂风呼啸而过 + 烛火噼啪作响 + 远处若有若无的虫鸣声 + 角色呼吸声

[7.色调光影] 主色调为冷青灰色(#3A4A5C)与深阴影(#1A1A2E)，点缀色为暖黄烛光(#D4A574)和冷白月光(#F0F0F0)。布光采用冷暖对比，烛光为暖色主光源，月光为冷色辅光源，形成强烈对比。整体对比度高，营造压抑氛围。

[8.情绪氛围] 整体画面昏暗压抑，透着凄凉与萧索。辛月影娇小的身躯在破败环境中显得无助，暗示她穿越后面临的艰难处境。烛光与月光的冷暖对比象征着她内心的迷茫与外界危机的冲突。画面充满悬念——她会如何面对这个陌生的世界？
```
**字数统计**：约650字，符合10秒视频的饱满度要求

### 饱满度检查清单（每个分镜必查）⭐⭐⭐

生成提示词后，**必须逐项检查以下内容**：

```markdown
□ [1.环境开场] 是否有详细的光线、色调、背景细节描述？（≥50字）
□ [2.角色位置] 角色在画面中的位置是否精确？（方位+距离+姿态）
□ [3.动作描述] 是否有完整的动作过程（起始→过程→结束）？
□ [4.表情变化] 是否有层次化的表情变化（A→B→C）？
□ [5.运镜细节] 是否包含运镜类型+速度+焦点+转场？
□ [6.声音元素] 是否有环境音/对白/音效描述？
□ [7.色调光影] 是否有具体的色调和布光描述？
□ [8.情绪氛围] 是否有情绪基调和剧情隐喻？
□ [9.画面质感] 是否有景深、细节度、特殊效果描述？（⭐必填）
□ 字数是否在范围内？（5秒：300-800字，10秒：500-1000字）
```

**如有任何一项不合格，必须重新修改提示词！**

### 画面质感（必填项）⭐⭐⭐

**每个视频提示词必须包含画面质感描述，不能省略！**

画面质感控制画面的精细度和视觉效果，是确保生成质量的关键要素。

**必须包含的内容**：
- **景深**: 极浅/浅/深，焦点在哪里
- **细节度**: 极高/高/标准
- **运动效果**: 运动模糊/稳定/手持感
- **特殊效果**: 瞳孔反射、光影粒子、镜头光晕等（如有）

**示例**：
```
【画面质感】景深: 极浅，只有眼睛清晰，背景高度虚化。细节度: 极高，虹膜纹理可见。急推效果: 轻微运动模糊。
```

### 公式详解

| 要素 | 说明 | 必须包含的细节 |
|------|------|----------------|
| **主体** | 视频中的核心角色/物体 | 外貌特征 + 服装细节 + 配饰道具 |
| **主体描述** | 外观、服装、表情等细节 | 发型、面容、体型、穿着、姿态 |
| **运动** | 主体的动作/运动轨迹 | 动作起始 → 过程 → 结束状态 |
| **场景** | 环境背景 | 时间、地点、主要物体 |
| **场景描述** | 场景细节 | 光线、色调、氛围元素、背景细节 |
| **镜头语言** | 运镜方式 | 景别变化 + 镜头运动方向 + 速度 |
| **光影** | 光线效果 | 主光源 + 辅助光 + 阴影效果 |
| **氛围** | 情绪氛围 | 情绪基调 + 叙事暗示 |

## 主体参考语法（重要）

### @主体名 指代规则

可灵3.0支持使用 `@主体名` 语法锁定角色和道具，确保多镜头间一致性。

**语法格式：**
- `【@图片1】` - 指代第1张参考图
- `【@图片1】（角色A）` - 带说明的指代
- `@角色名` - 使用角色主体名
- `@图片` - 指代参考图片

**官方示例：**
```
【@图片1】（拳击手A）
【@图片2】（拳击手B）
【@图片3】（场景-天台）

镜头1，2s 远景，【@图片1】 的拳击手 A 和【@图片2】 拳击手 B 在天台中央对峙，双脚分开呈拳击预备式
镜头2，2s 两人同时逼近，近身试探：【@图片1】 拳手A快速出拳，【@图片2】 拳击手 B 侧身格挡。
镜头3，3s，【@图片1】 拳击手 A 继续进攻，一拳打在【@图片2】 拳击手 B 的脑袋上，【@图片2】 拳击手 B 进行回击
```

### 主体参考最佳实践

1. **首次出现时定义**：`【@图片1】（角色名）` 建立关联
2. **后续使用简称**：直接用 `【@图片1】` 或 `@角色名`
3. **多角色场景**：每个角色分配独立的 `【@图片X】`
4. **场景图**：单独使用 `【@图片X】（场景-名称）`

## 指令变换（可灵 O1 核心能力）

### 什么是指令变换

可灵 O1 支持**用文字指令直接编辑已生成的视频**，无需重新生成，节省时间和成本。

### 指令变换能力列表

| 变换类型 | 提示词写法 | 效果 |
|----------|-----------|------|
| **去除路人** | "去除画面中的行人" | 清除背景人物 |
| **时间变换** | "将白天改为黄昏" | 调整时间氛围 |
| **服装更换** | "将她的红裙换成白裙" | 改变角色服装 |
| **天气变换** | "将晴天改为雨天" | 调整天气效果 |
| **风格重绘** | "改为赛博朋克风格" | 改变整体视觉风格 |
| **背景替换** | "将背景替换为森林" | 改变场景环境 |

### 指令变换使用场景

1. **视频后期修正**：生成的视频有小瑕疵时，用指令修正
2. **多版本生成**：生成一个基础版本后，快速生成不同风格变体
3. **成本优化**：避免因小问题重新生成完整视频

### 指令变换示例

**原始视频**：街道上行走的女子（白天场景）

**变换指令**：
```
# 场景1：时间变换
将白天改为黄昏，天空染上橙红色，街灯亮起

# 场景2：天气变换
将晴天改为雨天，雨水滴落在地面，女子撑起伞

# 场景3：去除路人
去除画面背景中所有的行人，只保留主角
```

### 指令变换最佳实践

1. **指令要具体**：明确说明变换的目标和效果
2. **一次一个变换**：避免同时修改太多元素
3. **保留原始文件**：指令变换前保存原始视频
4. **逐步迭代**：复杂修改分多步完成

## 运镜技巧（专业级）⭐⭐⭐

### 运镜设计完整框架


### 镜头类型（景别）详解

| 景别 | 英文术语 | 画面范围 | 情绪效果 | 适用场景 |
|------|----------|----------|----------|----------|
| **大远景** | Extreme Wide Shot (EWS) | 环境为主，人物极小 | 史诗感、孤独感、世界观 | 场景建立、时间流逝 |
| **远景** | Wide Shot (WS) | 全身 + 环境 | 空间关系、叙事 | 场景介绍、人物入场 |
| **全景** | Full Shot (FS) | 人物全身 | 动作完整性、体态 | 动作戏、走路、舞蹈 |
| **中景** | Medium Shot (MS) | 膝盖以上 | 对话、互动、日常 | 对话场景、互动 |
| **中近景** | Medium Close-Up (MCU) | 胸部以上 | 情感表达、亲密 | 情绪戏、对话特写 |
| **近景** | Close-Up (CU) | 肩膀以上 | 情感聚焦、心理 | 表情变化、情绪 |
| **特写** | Close-Up Face (CUF) | 面部为主 | 强烈情感、细节 | 情绪高潮、关键反应 |
| **极度特写** | Extreme Close-Up (ECU) | 眼睛/嘴唇/局部 | 极度情感、生理反应 | 震撼瞬间、瞳孔变化 |

### 镜头角度详解

| 角度 | 英文术语 | 视觉效果 | 情绪暗示 | 示例场景 |
|------|----------|----------|----------|----------|
| **平视** | Eye Level | 平等、自然 | 客观、日常 | 对话、日常场景 |
| **仰拍** | Low Angle | 主体高大 | 力量、压迫、崇敬 | 英雄、反派威压 |
| **俯拍** | High Angle | 主体渺小 | 脆弱、无助、上帝视角 | 受害者、困境 |
| **斜角** | Dutch Angle | 画面倾斜 | 不安、疯狂、混乱 | 心理崩溃、悬疑 |
| **鸟瞰** | Bird's Eye | 垂直俯视 | 全知、抽离、命运 | 战场、城市全景 |
| **虫视** | Worm's Eye | 极低仰拍 | 极度压迫、渺小 | 巨物恐惧、威胁 |

### 运镜方式详解

| 运镜类型 | 英文术语 | 提示词写法 | 效果 | 最佳时长 |
|----------|----------|-----------|------|----------|
| **推镜头** | Push In / Dolly In | "镜头缓慢/急速推近" | 聚焦、强调、揭示 | 2-4秒 |
| **拉镜头** | Pull Out / Dolly Out | "镜头缓慢/急速拉远" | 揭示环境、抽离、结束 | 2-4秒 |
| **急推** | Crash Zoom / Fast Zoom In | "镜头突然急速推近(crash zoom)" | 冲击、震惊、心理爆点 | 0.5-1秒 |
| **横移** | Truck / Track | "镜头横向移动/跟拍" | 展示空间、平行运动 | 3-5秒 |
| **升降** | Crane / Boom | "镜头上升/下降" | 视角变化、揭示 | 3-5秒 |
| **环绕** | Orbit / 360° | "镜头360度环绕[主体]旋转" | 立体感、戏剧性、时间停滞 | 5-8秒 |
| **跟随** | Follow / Tracking | "镜头跟随[主体]运动" | 代入感、速度感 | 全程 |
| **手持感** | Handheld | "轻微晃动的手持感" | 真实感、紧张、纪录 | 全程 |
| **固定** | Static / Locked | "镜头固定/静止" | 稳定、客观、观察 | 任意 |

## 视觉隐喻设计（高级技巧）⭐⭐⭐

### 什么是视觉隐喻

视觉隐喻是通过画面元素暗示角色内心、剧情走向或主题的高级技巧。

### 瞳孔反射隐喻

**最强大的视觉隐喻之一，用于展现角色内心世界：**

```markdown
【瞳孔中的视觉隐喻】
在3-8秒的极度特写中，瞳孔反射中隐约可见:
- 摇曳的烛光 (现实)
- 对面角色的模糊剪影 (现实威胁)
- 现代场景的灯光 (前世记忆碎片)
- 关键事件的闪光 (死亡记忆/重要回忆)
- 这些画面如玻璃碎片般一闪而过，象征身份的撕裂和重叠
```

### 常用视觉隐喻

| 隐喻类型 | 画面表现 | 象征意义 |
|----------|----------|----------|
| **镜子/倒影** | 角色看镜子，倒影与本人不同 | 身份分裂、内心矛盾 |
| **瞳孔反射** | 瞳孔中显示其他场景 | 内心世界、记忆、预知 |
| **影子** | 影子形状与本人不同 | 隐藏的自我、真实身份 |
| **破碎** | 镜子/玻璃破碎 | 世界观崩塌、身份撕裂 |
| **光/暗** | 角色一半在光中一半在暗 | 善恶对立、内心挣扎 |
| **水/雨** | 雨水冲刷、泪水 | 净化、悲伤、重生 |
| **花** | 花开/花谢 | 生命、美丽、脆弱 |
| **火** | 火焰燃烧 | 毁灭、愤怒、净化 |
| **笼/锁链** | 角色被束缚 | 困境、束缚、压抑 |

### 视觉隐喻示例

**示例1：穿越认知（瞳孔反射）**
```markdown
【瞳孔中的视觉隐喻】
在极度特写中，辛月影的瞳孔反射中隐约可见:
- 摇曳的烛光 (眼前的现实)
- 沈清起的模糊剪影 (现实威胁)
- 现代高速公路的灯光 (前世记忆碎片)
- 车祸瞬间的闪光 (死亡记忆)
这些画面如玻璃碎片般一闪而过，象征她身份的撕裂和重叠——她是辛月影，却也是曾经的现代人。
```

**示例2：内心挣扎（光影分割）**
```markdown
【视觉隐喻】
烛光从侧面照射，辛月影的脸一半沐浴在暖黄光中，一半隐没在阴影里。
这光影分割象征她内心的挣扎——一边是想活下去的本能，一边是身为"恶毒女配"的绝望认知。
```

|----------|----------|-----------|

### 特殊音效设计

| 时间点 | 音效类型 | 描述方式 | 情绪效果 |
|--------|----------|----------|----------|
| **冲击瞬间** | 心跳放大 | "急推时的心跳声突然放大 (咚——咚——)" | 震惊、紧张 |
| **认知冲击** | 高频耳鸣 | "持续的高频耳鸣声，象征认知冲击" | 心理压力 |
| **回忆闪现** | 混响音效 | "隐约的[声音]，非常微弱，混响感" | 记忆、超现实 |

### 背景音乐设计

| 情绪类型 | 乐器选择 | 节奏 | 音量 | 特殊处理 |
|----------|----------|------|------|----------|
| **震撼/超现实** | 高音弦乐单音 | 几乎静止 | 15%极低 | 音符拉长、时间扭曲 |
| **紧张/悬疑** | 低音弦乐 + 电子 | 缓慢不规则 | 30% | 不协和音程 |
| **悲伤/温情** | 钢琴/大提琴 | 缓慢 | 40% | 柔和延音 |
| **愤怒/冲突** | 打击乐 + 铜管 | 快速强烈 | 50% | 强重音 |

### 音效设计完整示例

```markdown
【音效设计】

环境音:
- 滴水声在急推瞬间戛然而止 (时间停滞感)
- 微弱的风声变得遥远模糊
- 烛火声几乎消失

特殊音效:
- 2-3秒: 急推时的心跳声突然放大 (咚——咚——)
- 3-6秒: 持续的高频耳鸣声，象征认知冲击
- 4-6秒: 隐约的汽车刹车声和碰撞声 (记忆碎片音效，非常微弱，混响感)
- 心跳声从急促到几乎停止

台词 (3秒左右出现):
- 说话人: 沈清起 (画外音，略带嘲讽的冷笑)
- 内容: "辛四娘，你还要装到什么时候？"
- 语气: 嘲讽，冷漠，带着看穿一切的戏谑
- 声音位置: 画外，略带混响，营造压迫感
- 时机: 在急推完成后，配合瞳孔放大的瞬间

背景音乐:
- 类型: 穿越震撼配乐
- 特点: 音符突然停顿，然后是单音延续
- 乐器: 高音弦乐单音持续，营造时间停滞感
- 节奏: 几乎静止，每一个音符都被拉长
- 音量: 15%，极低，突出心跳和耳鸣音效
- 情绪: 震撼，超现实，时间扭曲
- 特殊效果: 2-3秒急推时音乐突然放大然后骤降
```

## 音画同出（视频 2.6 核心能力）⭐重点

**视频 2.6 是最常用的音画同步模型，支持 5秒/10秒 时长。**

### 视频 2.6 官方公式（重要）

```
提示词 = 场景（场景描述）+ 主体（主体描述）+ 运动（运动描述）+ 音频（对话/唱歌/音效/纯音乐）+ 其他（风格/情感/镜头）
```

**核心原则**：只需写出【您想看到的画面】+【发生了什么动作】+【您希望出现的声音】

---

### 音频类型详解（视频 2.6）

#### 1. 对话

**格式**：`【【@图片X】，角色名，声音特质 + 情绪 + 地说道】："台词内容"`

**单角色示例**：
```
【【@图片1】，男人，低沉、焦急地喊道】："快跑！"
一个身穿黑衣的男人猛地推开房门，焦急地喊道"快跑！"，声音低沉而急促。
```

**多角色示例**：
```
【【@图片1】，A角色，愤怒地说道】："你骗了我！" 【【@图片2】，B角色，平静地回答道】："我没有。"
黑衣特工猛地拍了一下桌子，【【@图片1】，黑衣特工，愤怒地喊道】："真相在哪？"
女助手后退一步，【【@图片2】，女助手，声音颤抖地说道】："我真的不知道..."
```

#### 2. 唱歌

**格式**：`"歌词内容" + 演唱风格 + 伴奏描述 + 情绪`

**演唱风格**：流行唱腔 (Pop)、美声 (Opera)、乡村 (Country) 等
**情绪/技巧**：高亢地唱 (High-pitched)、颤音 (Vibrato)、温柔地唱

**示例**：
```
"月儿弯弯照九州..." + 轻柔的民谣风格 + 吉他伴奏 + 温柔地唱
一位身穿古装的女子站在月下，轻声哼唱"月儿弯弯照九州..."，温柔而忧伤。
```

#### 3. 说唱

**格式**：`"句子（押韵）" + 节奏流派 + 情绪`

**节奏流派**：强烈的 Boom Bap 节奏、Trap Style Beat、快速的 Flow
**内容要求**：句子要能体现押韵 (Rhyme) 和节拍 (Meter)

**示例**：
```
"街角的灯光照亮梦想，每一步都在向前闯" + 强烈的 Boom Bap 节奏 + 自信地
一位街头说唱歌手在霓虹灯下，跟着强烈的鼓点rap："街角的灯光照亮梦想，每一步都在向前闯"，自信满满。
```

#### 4. 音效

**格式**：`声音来源（动作/物体）+ 状态 + 专业拟声词`

**结构**：`【物体：木门】猛地【动作：关上】+【拟声词：砰】`

**示例**：
```
【物体：木门】猛地【动作：关上】+【拟声词：砰】
一阵风刮过，厚重的木门猛地关上，发出"砰"的一声巨响。

【物体：玻璃杯】从桌上【动作：摔落】+【拟声词：哗啦】
玻璃杯从桌上摔落，发出清脆的破碎声"哗啦"。
```

#### 5. 环境音

**格式**：`场景 + 声音组成元素 + 空间混响`

**元素**：雨声、虫鸣、人群低语、车流
**空间感**：空旷的礼堂回声 (Reverb)、狭小的室内混响 (Small Room Acoustic)

**示例**：
```
场景：夜晚的森林 + 元素：虫鸣、风声 + 空间感：空旷的回声
夜晚的森林，虫鸣声此起彼伏，远处传来风声，空旷而幽静。

场景：繁忙的十字路口 + 元素：车流、鸣笛声 + 空间感：城市的喧嚣
繁忙的十字路口，车流不息，鸣笛声此起彼伏，充满城市的喧嚣。
```

#### 6. 纯音乐

**格式**：`乐器类型 + 音乐流派 + 情绪`

**流派**：古典 (Classical)、摇滚 (Rock)、电子 (Electronic)、爵士 (Jazz)

**示例**：
```
钢琴演奏的 + 爵士乐 (Jazz) + 忧郁的 (Melancholy)
昏暗的爵士酒吧，钢琴手弹奏着忧郁的爵士乐，琴声悠扬。

古筝演奏的 + 古典 (Classical) + 悠扬的
古代庭院中，一位女子轻拨古筝，悠扬的琴声飘荡在月色中。
```

### 多角色对话 Prompt 范式（重点教学）

#### 核心原则 P1-P4

| 原则 | 要求 | 正确示例 | 错误示例 |
|------|------|----------|----------|
| **P1. 结构化命名** | 角色标签必须唯一且始终如一 | `【【@图片1】，黑衣特工，...】` 和 `【【@图片2】，女助手，...】` | `[特工]说...随后，他又说...` |
| **P2. 视觉锚定** | 将台词绑定到该角色的独有动作 | 黑衣特工猛地拍桌子。`【【@图片1】，黑衣特工，愤怒地喊道】`："真相在哪？" | `【【@图片1】，黑衣特工，愤怒地说道】`："真相在哪？"（无动作绑定） |
| **P3. 音频细节** | 为每个角色赋予独特的音色和情绪标签 | `【【@图片1】，黑衣特工，声音沙哑、低沉地说道】`："别动。" `【【@图片2】，女助手，声音清脆、恐惧地说道】`："我害怕。" | `[男人]说... [女人]说...`（太过模糊） |
| **P4. 时序控制** | 使用明确的连接词控制说话次序和节奏 | `...【【@图片1】，黑衣特工，...】`："为什么？" **紧接着**，`【【@图片2】，女助手，...】`："因为时间到了。" | `【【@图片1】，黑衣特工，...】`："为什么？"`【【@图片2】，女助手，...】`："因为时间到了。"（无连接词） |

```
【【@图片2】，女助手，声音清脆、恐惧地说道】："我...我真的不知道..."

这时候说话人切换。

黑衣特工站起身，逼近女助手。
【【@图片1】，黑衣特工，低沉、威胁地说道】："别装了，我最后问你一次。"
```

## 分镜叙事模式（可灵3.0 Omni 核心特性）

### 什么是分镜叙事

可灵3.0 Omni支持在**一个10秒视频**中生成**多个镜头**，AI会自动调度景别与机位，实现电影级的叙事效果。

### 分镜叙事 vs 传统单镜头

| 对比项 | 传统单镜头 | 分镜叙事 |
|--------|-----------|----------|
| 视频数量 | 每个镜头单独生成 | 多个镜头一次生成 |
| 角色一致性 | 需要首帧图衔接 | 使用 【@图片X】 自动保持 |
| 叙事连贯性 | 需要后期剪辑 | AI自动处理转场 |
| 效率 | 低 | 高（一次生成） |

### 分镜叙事提示词格式

**标准格式：**
```
[主体定义区]
【@图片1】（角色A）
【@图片2】（角色B）
【@图片3】（场景-场景名）

[分镜描述区]
镜头1，[时长]，[景别]，[动作描述]
镜头2，[时长]，[景别]，[动作描述]
镜头3，[时长]，[景别]，[动作描述]
...
```

### 分镜时长分配建议

**10秒视频分镜方案：**

| 方案 | 镜头配置 | 适用场景 |
|------|----------|----------|
| 快节奏 | 4镜头×2.5秒 | 动作戏、追逐、打斗 |
| 标准节奏 | 3镜头（3s+4s+3s） | 对话、情绪戏 |
| 慢节奏 | 2镜头×5秒 | 氛围展示、情绪铺垫 |

### 分镜叙事最佳实践

1. **时间总和必须等于视频时长**（如10秒）
2. **每个镜头要有明确的景别**：远景、中景、近景、特写
3. **动作要连贯**：上一镜头的结尾动作 = 下一镜头的起始状态
4. **善用 【@图片X】 语法**：确保角色一致性
5. **不要过度复杂**：10秒最多4个镜头，否则节奏太快
6. **每个分镜都要饱满**：遵循6维度要求，字数达标

### 衔接输入格式

当处理视频 N（N > 1）时，从上一个视频的"输出给下一分镜"获取信息：

```yaml
continuity:
  previous_shot: K0X-1
  tail_frame_time: 第X秒
  ending_action: 上一视频最后一个分镜的结尾动作
  ending_position: 角色最终位置
  ending_expression: 角色最终表情
  ending_state: 最终画面状态
  transition_note: 衔接要点说明
```

### 首帧图片使用

可灵动画支持"首帧 + 提示词"模式：
1. 从上一视频中截取尾帧（最后1秒的帧）
2. 上传作为当前视频的首帧图片
3. 首帧图片确保视频起点的连贯性

### 衔接质量检查

生成提示词后，检查以下要素：
- [ ] 除第一个视频外，是否包含"上一个分镜"信息
- [ ] "上一个分镜"是否准确引用了上一视频的结尾状态
- [ ] 当前视频的动作是否与上一视频结尾动作衔接
- [ ] 是否输出了"给下一分镜"信息
- [ ] 角色位置/表情是否与上一视频结尾一致

## 常见问题

### 动作不流畅
- 添加动作衔接词："然后"、"顺势"、"借助"
- 描述动作的因果链

### 表情僵硬
- 使用层次化情绪描述（箭头连接）
- 添加微表情细节

### 画面不够冲击
- 加强运镜描述
- 添加物理细节
- 使用更强的风格关键词
