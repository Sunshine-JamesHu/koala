# 分镜审查技能

## 触发方式
当用户要求审查分镜、检查分镜描述准确性时触发此技能。

## 审查流程

### 1. 加载原文
读取小说章节原文：
- 路径: `works/{作品名}/novel/chapters/chapter_XXX.txt`

### 2. 加载分镜文件
读取生成的分镜Markdown文件：
- 路径: `works/{作品名}/output/episode_XXX/shot_XXX.md`
- 先读取 `README.md` 了解分镜索引

### 3. 逐个审查

对每个分镜进行以下审查：

#### 角色描述准确性
- 角色性别、年龄、外貌是否正确
- 表情是否符合当前情绪/台词
- 服装是否符合场景和剧情

#### 场景描述准确性
- 地点是否正确
- 时间（白天/夜晚）是否正确
- 天气/氛围是否符合剧情

#### 镜头语言准确性
- 景别（远景/中景/近景/特写）是否合适
- 角度（平视/俯视/仰视）是否合适

#### 动态描述准确性
- 首帧到尾帧的表情变化是否合理
- 运镜描述是否与实际镜头一致

#### 视频提示词完整性
- 是否包含完整的场景设定
- 是否包含角色动态描述
- 是否包含运镜描述

### 4. 输出格式

发现问题时，直接修改对应的shot_XXX.md文件，并报告：

```
## 审查结果

### shot_XXX
- 问题: [具体问题描述]
- 修正: [修正内容]

### shot_YYY
- 问题: [具体问题描述]
- 修正: [修正内容]

...

总计: X个分镜已修正
```

## 示例

用户: "审查episode_001的分镜"

Agent应该:
1. 读取 `works/穿书后我攻略了奸臣首辅/novel/chapters/chapter_001.txt`
2. 读取 `works/穿书后我攻略了奸臣首辅/output/episode_001/README.md` 了解分镜结构
3. 逐个读取shot_001.md到shot_019.md
4. 对比原文分析每个分镜的描述是否准确
5. 发现问题直接修改文件
6. 输出审查结果摘要
