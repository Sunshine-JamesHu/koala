启动计划模式完成如下功能

简化本程序的工作流，简化为 
小说主体阅读 
-> 生成大纲(稍微详细点，已经生成跳过这一步) 
-> 定整体风格(人物音色，整体的风格等，如果已经定过了就跳过)
-> 根据大纲+指定章节+前一章节的分镜脚本生成指定章节的(角色(已经生成了角色就跳过)，场景，分镜脚本) 
-> 输出角色和场景的 Nano Banana Pro 的图片提示词，增量在上一章的分镜中找到了合适的就直接告知使用即可
-> 根据分镜输出 Keling 的视频提示词 
-> 根据输出的视频提示词输出生成视频所需的图片提示词(首帧图 尾帧图 连贯的9分镜组合图) 
-> 审核分镜和提示词，包括视频和图片(分镜的运镜是否流程,是不是符合原文，有没有错别字)

最终都是为了生成视频服务的，拿到产物后人工操作流程如下
读取视频生成提示词查看所需图片-> 查看图片提示词 -> 一张一张生成所需图片 -> 拿图片生成视频 
这里要明确告知客户要使用哪张图片+哪些图片+使用哪个提示词才能生成这张图片，然后告知客户要使用哪些图片才能生成视频

提示词要傻瓜式 最好就是客户上传图片+拷贝提示词 点击生成即可。

以前的工作流过于复杂，且产物过多，而且视频提示词生成的东西也不够理想。

注意： 
Keling的支持任意秒数，支持首尾帧，支持多图参考(最多5张)，在设计的时候一定要考虑到这一点。
以前的角色生成可以参考，场景生成的时候那个场景8视图是有问题的，空间的透视和摆设是不对的，视频的提示词那边也不太对需要整改。

输出要求：
输出的东西会比较大，所以分开不同分镜输出
output/chapter_{001,002}/shot_{001,002}
output/chapter_{001,002}/scene/ (只有这个章节用的场景)
output/chapter_{001,002}/character/ (只有这个章节用的人物)
output/character/{辛影月,沈轻起}/ (多章使用的人物)
output/scene/{沈家小院}/ (多章使用的场景)
